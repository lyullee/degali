# Security and safety policy

DEGALI is scientific research software, not a certified safety instrument.
Do not use an unreviewed result as the sole basis for equipment design,
separation distances, emergency planning or regulatory compliance.

Report software vulnerabilities privately to the repository maintainer rather
than opening a public issue. The maintainer contact must be added in the GitHub
repository settings before publication.

For a suspected modelling error, open a reproducible issue that identifies the
model path, input assumptions, units, expected conservation or limiting
behaviour, and any independent experimental source. Do not include proprietary
facility data or credentials.
