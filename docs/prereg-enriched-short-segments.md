# 보완 형상의 조건부 짧은 하류 연결 — 실행 전 명세

2026-09-06. 동시 초기화 통과와 하류 계산은 다른 검사다. 먼저7개 초기화
결과를 확인한다. 실패 초기조건을 건너뛰어 전체7개 통과라고 부르지 않는다.
국소 통과 조건에서만 아래 드라이버를 시험할 수 있다.

## 상태 이동과 혼합률 갱신

기존 gauge-free 상태를 그대로 적분한다:
log(rho_c),log(Cc),log(A),theta,log(uc),x,z,C/H 모드.
각 평가마다 실제 중심 엔탈피, 물성, 폭/바람 기하, 상평형 적분망과 모든
모드 변화율을 새로 계산한다. 초기6개 모멘트로 하류를 다시 맞추지 않는다.
하류의5개 실제 총플럭스 변화가 적분된 원항과 일치하는지 확인한다.

chi_C를 초기 값 그대로 유지하는 대신, 명시적인 두 조건부 갱신을 분리한다.
L=sqrt(A), U=uc는 주변 풍속을 뺀 속도 크기다. 초기 chi_0(q)의 단면 형상은
유지하되 진폭은 다음과 같이 바뀐다. 기하평균 물리 확산률은D_eff=chi*A다.

1. 주 검사 `equilibrium_velocity_width`:
   chi(q,s)=chi_0(q)*(U/U0)*sqrt(A0/A), 즉D_eff 비율=(U/U0)*sqrt(A/A0).
2. 대안 `constant_geometric_diffusivity`:
   chi(q,s)=chi_0(q)*A0/A. D_eff만 일정하며, 폭 비가 바뀌면 각 방향
   D_y=chi*sy²,D_n=chi*sn²는 달라질 수 있다.

[Cafiero·Obligado·Vassilicos의 원문](https://arxiv.org/html/1811.02444)의
식5·10·11과 표1은 자유 전단류에서 속도×폭 척도와 일정 와점성 척도를
구분한다. 이 연구는 평면 제트/후류의 자기유사 구간을 다루며 극저온
수소·상변화·교차풍의 검증이 아니다. 여기서는 **초기 비균일 혼합률
형상에 진폭 척도를 적용하는 조건부 확장**을 시험하는 것이다.
두 경우 중 관측에 잘 맞는 것을 사후 골라 확립된 폐쇄식으로 쓰지 않는다.
이 갱신에는 새 실측 계수, epsilon/k 초기값 또는 자유 조정 상수가 없다.
열/수소 확산률비1 및 기존 축약 즉시 전단 열전환 가정은 유지한다.

초기 혼합 입력의 두 번째 열인 옛 질량 유량은 잔차 분모용 참조값이다.
새 실제 질량 유량으로 재사용하지 않는다. 새 f_M/f_P/f_K는 항상 재계산한다.
기존 입력 상평형 절단점은 chi_0의 고정 형상에 속한다. 새 물성의 절단점도
별도로 재구성해 모두 적분한다. 치수적으로 가능한 갱신이 물리적으로
검증된 난류 수송이라는 뜻은 아니다.

## 구간과 수치 판정

초기 미분의129² 표본에서 각 log 형상의 앞으로 향하는±0.1 경계까지
거리 h_shape를 구한다. 이것은 국소 선형 예측이지 해의 유효길이 증명이 아니다.
길이는 min(0.005 m, 0.05*min(sy,sn), 0.2*h_shape)로 사전에 정한다.
너무 짧은 구간을6 m 현장 계산의 통과로 표현하지 않는다.

주 검사에서 중점법2/4/8분할을 각각 초기 상태부터 수행한다. RHS는 새 상태의
반경8차/각도48점 망을 매번 만든다. 면33개 cosine 광선과 실제 적분 광선을
함께 검사한다. 각 RHS에서5% 스칼라/운동량 경계, 비음수 표본 chi_P,
면 유입, 곡률×반폭<0.1, 양의 밀도/0<Y<1 및 log 형상±0.1를 요구한다.
물리 조건을 깨는 경우 적분을 멈추고 마지막 도달 지점과 사유를 기록한다.
형상을 재적합해 경계 실패를 덮거나, log 상한을 자동 완화하지 않는다.

독립 정밀 초기/끝 총플럭스는 움직이는 상평형 적분8/8로 평가한다.
최종8분할 결과에서 플럭스 변화−누적 원항의 정규화 잔차<=1e-5,
4/8분할 상태 차이<=1e-5를 요구한다. 정밀 끝점의 수송4/8 대8/16
변화율/행렬 차이<=1e-5, 선형/영차 열수지<=1e-8와 질량 경계수지를 검사한다.
별도65고정각도/반경16차 및129² 물성에서도 초기화와 같은 물리 기준을 쓴다.
RHS 경계 검사가 실패하면 그 경로는 통과하지 않는다. 다른 분할은 실패를
삭제하지 않고 따로 기록할 수 있다.

주 검사2/4/8이 모두 통과한 조건에만 대안 갱신의8분할을 추가한다.
두 갱신의 끝 상태/혼합률/단면 차이는 폐쇄 가정 민감도로 보고한다.
대안을 주 검사 실패의 사후 대체 성공으로 사용하지 않는다.
두 갱신 모두 실패하면 상태 방정식/경계의 접선 적합성부터 조사한다.

기본 모델, 현장 점수 또는 장거리 검증으로 승격하지 않는다. 전체 실측
비교는 이 단계를 통과하고 필요한 거리/관측 연산까지 도달할 때만 수행한다.
