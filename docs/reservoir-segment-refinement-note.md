# 초기 8분할 미통과 구간의 별도 수치 세분화

2026-09-05. `reservoir_thermal_segments_2026-09-05.json`에서 7개 경계 약형과
수치 미분은 통과했다. 지정한 2/4/8분할 구간은 6/7 통과했으나 시험 10의
8분할 수지 잔차가 1.254e-5로 원래 1e-5 기준에 미달했다. 해당 원본을
성공으로 바꾸지 않는다. 이것은 결과를 본 뒤 지정하는 별도 수치 검증이다.

원래 미통과 시험만 동일 초기 상태·길이·물리식·8차 상평형 셀 분할을
유지한 채 중점 RK2 16/32/64분할로 다시 계산한다. 64분할 6개 수지 잔차와
32/64 로그상태 종점 차를 각각 기존 기준 1e-5로 검사한다. 끝점에서는
16차/1025 표본의 원래 물성·양성·유입·곡률 게이트를 적용한다.

이는 상평형 표의 기울기 변화로 매끄럽지 않은 RHS를 공간 방향으로 더
세밀히 적분하는 검증이다. 단계 오차가 단조 감소한다고 가정하지 않는다.
계수, 초기 경계, 계산 길이, 상태 표현, 물성표, 실패 기준을 바꾸지 않는다.
64분할도 미달하면 실패로 남긴다. 물리 플럭스의 큰 점별 경계 결함은
이 수치 검증과 별개로 유지되며 현장 점수/기본 모델 승격은 하지 않는다.
