# 열수지 실패의 경계 항 분해 — 후속 진단 명세

`shear_thermal_compatibility_2026-09-05.json`의 7/7 수치 통과, 0/7 물리
양립 결과를 본 뒤 수행하는 **사후 원인 분석**이다. 원래 선별의 기준을
수정하거나 재분류하지 않는다. 새 물리 계수를 선택하지 않는다.

1. 원래 코드/입력 해시를 검사하고 같은 실제 소스, 경계, gamma 후보를 쓴다.
2. 네 면의 엔탈피 플럭스를 `h*f_M`(이동 경계를 뺀 대류)와
   `-A*rho*chi_C*h_q`(등확산 가정의 난류 확산)으로 따로 적분한다.
   두 항의 합이 원래 기록된 열 경계 항을 1e-5 이내로 재생하는지 검사한다.
   원래 극성, 유한 사각형 및 상평형 셀 분할을 유지한다.
3. 가장자리 q0~2q0에서 온도 범위와 남아 있는 H/Hc를 기록한다.
   이것은 실제 관측된 외곽 온도가 아니라 **현재 단면 가정의 예측**이다.
4. 두 확산률의 표본 필요조건이 주는 gamma 구간에서 R0의 양 끝 값을 검사한다.
   아핀 R0가 구간 전체에서 0이 될 수 없는지 판단한다. 양의 확산률 구간은
   표본 필요조건이므로, 이 넓은 구간에서도 불가능하면 실제 허용 구간에서도
   불가능하다. 통과하더라도 전 반경 양성을 입증하지는 않는다.
5. `Q=eta*P, 0<=eta<=1`로 바꿀 때 같은 다섯 원항/단면에서의 잔차는
   `R0+(1-eta)*P`이다. gamma와 eta 직사각형의 네 꼭짓점을 검사한다.
   이는 즉시 열전환을 줄이기만 하는 변형의 가능성 검사이지, 완전한 TKE
   수송 모형(에너지 상태/경계/프로파일까지 바뀜)을 반증하는 검사가 아니다.

유입부의 주변 공기 엔탈피를 0으로 잡는 기존 에너지 원항과, 아직 차가운
유한 경계의 대류·확산이 동시에 성립하는지 구별한다. 단면을 넓히거나
가장자리 열을 0으로 덮어쓰거나 확산률 비를 맞추는 처리는 하지 않는다.
