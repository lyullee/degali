# 미해상 열·조성 혼합과 평균 EOS — 사전 계획 2026-09-06

완료한 액상·기계에너지·접선 검사를 반복하지 않는다. 현재 단일 상태의
EOS 평가와 불균일 유체의 평균이 동일한지, 같은 저장 상태의 국소 보존량을
바꾸지 않는 **분포 가능성 검사**를 한다. PDF 분산/시간척도/난류 상수를
선택하거나 실제 필드 예측으로 채택하지 않는다.

## 평균 정의와 보존 조건

질량 가중 이산 확률 w_i>=0, 합1에 대해

```
Y_F = sum(w_i*Y_i); h_F = sum(w_i*h_i)
v_F = sum(w_i/rho_i); rho_R = 1/v_F
p_R,i = (w_i/rho_i)/v_F
T_F = sum(w_i*T_i); T_R = sum(p_R,i*T_i)
```

가변밀도에서 질량가중/보통 평균 구분은
[NASA TMR 정의](https://tmbwg.github.io/turbmodels/implementrans.html)에 따른다.
위 이산 변환은 그 정의의 본 프로젝트 유도다. 시간 평균과 해석하려면
정상·통계적 표본 가정이 추가로 필요하다. 센서 반응/궤적 흔들림 모델은 아니다.

실제 각 점의 (rho0,Y0,h0)를 고정하여 합w=1, 합wY=Y0, 합wh=h0,
합wv=1/rho0을 동시에 만족시킨다. 각 미소상태에 같은 속도를 가정하면
평균 질량·성분·운동량·열+평균KE도 그대로다. 속도 상관이나 실제 난류장이
구성됐다는 뜻은 아니다. 압력과 주변 공기 성분/습도는 같은 시험의 값을 쓴다.

이 조건 아래 T_R의 최소/최대와 원래 p05/중앙온도 이하의 p_R 최대값을
선형계획으로 구한다. 이는 분포를 맞춘 모형이 아니라 제약된 분포 집합의
극값이다. 극값을 준 분포는 최적화 증거로만 저장하고 수송 후보로 사용하지 않는다.
최저온도는 특정 분위수로 간주하지 않고 이 단계 목적함수에서 제외한다.
평균온도 범위를 관측 중앙값의 오차 점수로도 쓰지 않는다.

구현 전 추가 명세: 같은 rho/Y/h를 유지해도 체적/시간 평균 H2 몰분율은
자동으로 같아지지 않는다. 현재 point_mole_fraction은 응축 성분도 포함한
전체 혼합물을 기체로 환산한 X(Y)를 쓴다. 따라서4모멘트 조건과, 추가로
이 **기존 보고 연산자**의 예측 X0를 고정하는 `sum(w*v*X)=v0*X0`의
5모멘트 조건을 함께 검사한다. X0는 관측값이 아니다. 응축 성분을 제외한
실제 기체상 몰분율 X_g도 별도로 기록하며 두 정의를 섞지 않는다.
원래 보고 농도까지 유지한 효과와 농도 변화를 허용한 효과를 구분한다.

## 표본/열역학 범위 고정

- 기존 pressure-loss CONTROL의 같은41온도 지점, 같은 지면 반사/저장
  궤적 재생. 원래 lookup 예측을 재생 확인한 뒤 정확 EOS의 h/T를 사용하고
  두 온도 차이를 별도로 기록한다. 새 ODE는 적분하지 않는다.
- 기존 독립 순수응축/물·기체 장부를 그대로 사용한다. 새 액상 모듈이나
  불완전한 혼합고체를 결합하지 않는다. 결과는 이 기존 EOS에 조건부다.
- 두 지지범위 하한50K/65K를 사전 지정하고 상한은 각 시험 주변 온도로 한다.
  전자는 기존 저온 응축 가정에 더 의존한다. 둘 다 물리적 최저온도 주장이나
  관측에 맞춘 경계가 아니다. 범위 밖의 최적 분포 가능성을 배제하지 않는다.
- 온도33→65등분, Y의 양의 선형33→65점과 log10 Y=-6..-1의33→65점
  합집합을 중첩망으로 사용한다. Y=0은 실제 주변 상태 한 점만 추가한다.
  실제 원래 상태를 한 점 추가하여 원래 단일상태 분포가 항상 가능하게 한다.
- CDF의 불연속 적분을 위해 해당 원래 p05/중앙온도와 전체Y망의 선을
  각 망에 똑같이 추가한다. 이는 목적함수 경계의 수치 정렬이며 온도 피팅 아니다.
  원래 지점 온도가 지지범위 밖이면 원래 상태 추가 사실과 범위를 표시한다.

## 독립 검사와 판정

평균 변환·질량/체적의 직접 재구성·성분별 엔탈피 기준 변경·단일상태 극한을
검사한다. 선형계획 결과는 원래 단위의 모멘트, 비음수, 유한 지지망의
쌍대 조건과 목적함수 차이로 확인한다. 보존 정규화 잔차<=1e-8, 쌍대
정규화 잔차/간극<=1e-8. 온도범위 망 차이<=0.5K, CDF 차이<=.01이면
이 두 망 사이만 수치해결로 표시하고 아니면 미해결을 보존한다.

유한망의 극값은 연속 물리 지지공간의 엄밀 상한/하한이 아니다. 따라서
CDF 최대값이0.5/0.05보다 작다고 실제 중앙값/p05가 물리적으로 불가능하다고
단정하지 않는다. 반대로 가능 분포가 존재해도 실제 유동이 그 분포라는
증거는 아니다. 이 검사는 평균 EOS 미폐쇄가 무시할 수 있는지를 선별할 뿐,
실제 분포의 운반/혼합/소산 법칙과 검증은 다음 독립 과제다.
