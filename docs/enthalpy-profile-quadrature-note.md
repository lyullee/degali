# 체적 엔탈피 후보의 적분 검사 보완 — 2026-09-05

이 문서는 사전 물리 가정이나 판정 허용오차의 변경이 아니라, 계산 중 발견한
불충분한 수치 검사를 기록한다. 원래 등록 문서는 그대로 보존한다.

## 발견

기존 밀도 가우스 경로에서는 일부 플럭스를 해석적으로 적분할 수 있어,
수치 적분 차수의 판정은 에너지 중심이었다. 새 체적 엔탈피 경로의 밀도는
상평형 역산으로 결정되며 일반적으로 가우스가 아니다. 에너지 수렴만으로
질량과 운동량 적분의 수렴을 보장할 수 없다.

최초 64차 텐서 적분의 7개 접속 결과는
`gaussian_enthalpy_profile_interface_2026-09-05.json`에 보존한다.
그러나 시험 23의 같은 접속 상태를 256차로 재적분하면 질량 플럭스는
약 3.54e-5, 수평 운동량은 5.17e-5 달라졌다. 에너지 차이는 3.44e-8에
불과했다. 따라서 이 최초 파일은 **최종 수치 승인 결과가 아니다**.
이를 사용하던 하류 계산 세 개는 결과 JSON 저장 전에 중단했다.

## 수정한 수치 방법

각 플럭스의 단면 피적분함수는 `q=pi*(a²+b²)/8`에만 의존한다.
기존 유한 정사각형 영역을 유지한 채 다음 두 구간으로 정확히 변수 변환한다.

- `q0=pi*delta²/8`, `0<=q<=q0`: 가중치 `2*pi*dq`.
- `q=q0*(1+t²)`, `0<=t<=1`: 가중치
  `(2*pi-8*atan(t))*2*q0*t*dt`.

두 번째 항은 정사각형 모서리 부분이다. 영역을 원으로 자르거나 적분 경계를
변경하지 않았다. 각 구간에 Gauss–Legendre 적분을 적용하므로 국소 상평형
역산 개수는 텐서 적분의 제곱 증가 대신 차수에 비례한다.
가우스 거듭제곱의 해석적 정사각형 적분과 면적 검사를 별도 단위시험으로 둔다.

새 후보에서는 차수를 늘렸을 때 **다섯 플럭스 모두의 최대 상대 변화**를
기존 1e-5 기준으로 검사한다. 기존 기본 모델의 에너지 판정은 변경하지 않는다.
전체 하류 계산 후에는 시험마다 9개 저장 단면에서 차수를 다시 2배/4배로
늘려 같은 기준을 검사한다. 이 수치 검사는 관측 오차의 개선과 별개다.

새 승인 파일은 `gaussian_enthalpy_profile_allflux_interface_2026-09-05.json`이며,
`polar_square_all_flux_v1` 표지가 없는 옛 접속 파일은 새 하류 실행에서 거부한다.
혼합한 적분 방식의 결과 파일 병합도 거부한다.
