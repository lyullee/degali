# 실제 기계/열 에너지 규모 진단 —2026-09-06

계산 전 고정. 앞선 냉각 범위에서 위치만으로 설명되지 않은 근접장 잔차가
남았다. 다음은 직접적인 평균KE→난류저장→열 전환의 규모를 조사한다.
새 초기 k나 소산시간을 실측 온도에 맞추는 작업이 아니다.

## 방법

1. 완료된 pressure-loss/Coriolis density10/23 네 궤적을 재생한다.
   실제 저장된 모든 상태에서 평균KE 유량 K=.5∫rho*u³dA를 Gaussian
   다항식의 해석적 적분으로 계산한다. 총에너지 E는 원래 저장값이다.
   H=E-K는 기존 모델에서 주변 엔탈피를 뺀 열 유량이다.
2. 최초 상태, 관측 거리의 가장 가까운 저장 상태, 마지막 상태에서 별도
   단면 구적의 ∫rho*h*u와 K가 해석식/저장값을 재현하는지 검사한다.
   상태 보간이 5플럭스 보존을 정확히 유지하지 않으므로 예산에는 실제
   저장 노드만 쓰고 관측 거리와 차이를 기록한다. 센서 점수를 바꾸지 않는다.
3. 모델에 포함된 누적 주변 기계 에너지 유입 I_E와 H-H0=I_E-(K-K0)
   잔차를 확인한다. K0+I_E는 **이 구현이 접속 이후 계상하는 기계 예산**이다.
   상류의 미해결 초기TKE, 압력일/부력일, 실제 난류 열수송을 포함하는
   보편적 상한으로 주장하지 않는다.
4. 같은 노드에서 ∫rho*u*Cp_gas(T,Y)dA를 계산해 K/Cdot을 기록한다.
   이는 기존 질량유량 가중의 균일 미소 현열 온도 규모다. 혼상 유효Cp를
   포함하지 않으며 국소 센서의 냉각 가능 상한도 아니다.
5. 별도로 원래 방출축11개 센서의 x에서 현재 반사 단면 최고형상 위치의
   T,Y를 유지하고, 같은Y에서 h(T_current)-h(T_observed)를 계산한다.
   원래14.1--300K 독립 순수응축 물성을 정방향으로 재구성하고 정확 역산과
   대조한다. 최저/p05/중앙값을 모두 유지한다. Δh는 조건부 비열량 규모이며
   실제 관측 조성을 알고 있다는 뜻이 아니다. 최대 평균속도의 .5U²와
   크기를 비교하되 이 점별 값에 전체 유량을 곱해 실제 요구W로 만들지 않는다.

## 채택/해석

수치 근거가 뒷받침되지 않으면 결과를 저장하되 해당 진단을 미해결로 둔다.
기계 예산이 작으면 직접적인 에너지 저장만으로 넓은 차가운 중심부가
설명된다고 주장하지 않는다. 난류에 의한 **열·성분의 재분포**는 총열량이
거의 일정해도 중심T를 크게 바꿀 수 있으므로 별도 문제로 유지한다.
잠열을 외부 열원으로 더하거나 기존 에너지를 버리는 후보는 만들지 않는다.

이 구분의 일반적인 방정식 근거는 NASA TMR의 Favre 총에너지·난류 열유량·
응력일 표현이다. 해당 문서의 일정gamma/공기 Prt를 LH2에 적용하지 않는다.
