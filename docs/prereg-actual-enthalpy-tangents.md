# 실제 단면의 열/조성 엔탈피 구배 선별 —2026-09-06

수송 계수와 모델을 바꾸기 전에 결과가 고정된 일곱 pressure-loss density
CONTROL의 실제 단면에서 h_T,h_Y와 공간구배를 검사한다. 새 난류 계수를
선택하거나 관측 온도에 맞추는 계산이 아니다. 비-slow 스냅샷 회귀가
완료한 뒤 별도 도구로 실행하며 기존 해시 고정 소스는 편집하지 않는다.

## 고정 표본

각 시험에서 초기 저장노드와 원래38농도 관측 거리의 가장 가까운 실제
저장노드를 고른다. 보간5플럭스를 실제 보존 수지로 쓰지 않는다. 각 단면의
원래 Gaussian 지수 q=-ln(shape)에 대해 q=0,.125,.25,.5,1,2,4를 쓴다.
이것은 원래 반사 전 단면의 물성 진단이다. 지면 센서 연산자나 관측점 선택을
바꾸지 않으며 새38/17/41 점수를 만들지 않는다.

## 독립 수치 검사

- rho=rhoa+(rhoc-rhoa)*exp(-q), C=rhoc*Yc*exp(-q), Y=C/rho.
- 원래 정확 EOS의 T와 h=H/rho를 평가한 뒤 별도 정방향14.1--300K
  독립 순수응축 조합으로 rho,h를 재현한다.
- h_T와 h_Y는 고정Y/고정T의 중앙차분으로 각각 구하고 간격을 절반으로
  줄여 검사한다. 초기 dT=.002K, dY=min(1e-5,.005*min(Y,1-Y)).
- q방향은 초기dq=1e-4,절반 간격을 써서 T_q,h_q를 원래 정확 EOS에서
  직접 구한다. Y_q=-C*rhoa/rho²는 해석식으로 별도 확인한다.
- 체인 규칙 h_q=h_T*T_q+h_Y*Y_q를 검사한다. 각 항의 크기 또는1로
  정규화한 잔차<=1e-3, h_T>0, 파생량 간격 변화<=1e-3을 선별 기준으로
  둔다. 표본이 상경계/물성 보간 절점에서 이를 만족하지 못하면 값을
  버리지 않고 nondifferentiable_or_unresolved로 표시한다.
- q=0의 실제 공간구배는 대칭으로0이다. q>0에서는 원래 수직 폭 sz에
  대해 dq/dz=sqrt(2q)/sz로 물리적 길이 구배로 바꾼다.

## 확산률을 지정하지 않는 단위 응답

J_H/DY=-rho*[r*grad(h)+(1-r)*h_Y*grad(Y)],r=DT/DY이므로

```
d(J_H/DY)/dr = -rho*(grad(h)-h_Y*grad(Y))
```

이다. 이 응답을 단순 h구배식의 -rho*grad(h)와 비교한다. r 자체를
선택하지 않으며 단위 응답을 실제 W/m² 유량으로 부르지 않는다.
조성 기여 h_Y*Y_q/h_q와 열 기여 h_T*T_q/h_q를 함께 기록한다. 분모가
너무 작으면 비율은 미정으로 남긴다. 온도만의 응답이 엔탈피 기준변경
h'=h+aY+b에 무관한지도 확인한다.

## 적용 범위

모든 결과는 현재 단일T·같은속도·평형 상분할에 조건부다. 기체/물응축/
건조공기응축을 구분하고, 혼상 h_Y를 실제 독립 입자의 확산 엔탈피로
확정하지 않는다. 순수기체에서의 관계와 같은확산률 일치부터 사용한다.
기존 모든 느린 약형/TKE 제조검사를 반복하지 않는다. 이 단계 결과가
크더라도 실제 수송 경계/약형을 보존 연결하기 전에는 개선으로 채택하지 않는다.
