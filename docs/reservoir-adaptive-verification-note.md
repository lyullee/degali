# RK2 비단조 수렴 뒤의 독립 적응형 적분 확인

2026-09-05. 원래 8분할과 별도 16/32/64분할 결과를 모두 보존한다.
시험 10은 64분할 수지가 7.651e-6으로 통과했지만 32/64 로그상태 차가
2.627e-5로 미달했다. 따라서 64분할 검증도 성공으로 재분류하지 않는다.

이 결과를 본 뒤, 같은 물리식/8차 상평형 셀 분할/초기 상태/길이에 대해
DOP853 적응형 적분을 rtol=1e-8,1e-10 두 번 수행한다. 각 성분의 atol은
rtol*0.01*척도이며, 로그상태 척도는 max(abs(initial),1), 누적 6개 플럭스의
척도는 이전 초기 플럭스 척도다. 최대 간격은 길이/16이다. 한 적분당
RHS 최대 2000회에서 중단한다. 상태와 6개 누적 원항을 함께 적분한다.

끝점은 16차/1025 표본으로 검사한다. 두 허용오차 실행의 로그상태 차와
조밀 실행의 6개 물리 플럭스 수지는 각각 원래 기준 1e-5를 유지한다.
이 검증도 실패하면 그 상태로 남긴다. 내부 오차 제어는 물리 해 정확도의
증명이 아니므로 실제 플럭스 변화 수지가 별도로 필요하다. 점별 경계의
성분/열 플럭스 결함은 수치 방법을 바꿔도 없어지지 않으며 별도로 보존한다.
