## 평균 정의와 물리 범위

질량 확률 w_i, 비체적 v_i=1/rho_i를 사용한다.

```
sum(w)=1; Y_F=sum(w*Y); h_F=sum(w*h); v_F=sum(w*v)
rho_R=1/v_F; p_R=w*v/v_F
T_F=sum(w*T); T_R=sum(p_R*T)
```

[NASA TMR의 Reynolds/Favre 정의](https://tmbwg.github.io/turbmodels/implementrans.html)를
평균 구분에 사용했다. NASA의 상온 공기 상수/Prandtl 수는 가져오지 않았다.
각 parcel의 속도가 원래 지점 속도와 같다는 조건에서는 위 제약이 기존
질량·성분·운동량·총 엔탈피+평균 운동에너지 상태를 유지한다. 서로 다른
속도/TKE, 동역학적 실현 경로, 엔트로피 생성 및 프로브 응답은 평가하지 않았다.
시간 기록과 공간 앙상블의 대응도 자동으로 성립한다고 가정하지 않는다.

같은41센서×50/65 K 하한, 실제 주변온도 상한. coarse33/fine65,
필요한 목적함수만 extra-fine129의 중첩 온도/조성 지지망에서 검사했다.
원래 균일 지점 상태를 항상 포함하고 관측 p05/median의 CDF 불연속 경계를
망에 정렬했다. 이는 수치 적분 규칙이지 관측에 맞춘 새 물리 계수가 아니다.
지지망의 평형은 원래 독립 N2/O2/물 응축 EOS다. 새 혼합 고체나 비이상
액상 후보를 이용한 결과가 아니며, 유한망 극값을 연속 상태공간의 보편적
상·하한이라고 주장하지 않는다.

기본4개 제약 외에 기존 보고농도 평균을 고정한5번째 제약도 별도 검사했다.
기존 `point_mole_fraction`은 총 수소/총 공기 몰수를 변환한 값으로, 응축된
공기를 뺀 실제 기상 몰분율과 다를 수 있다. 새 감사는 원래 보고 연산자를
보존하고 기상 농도를 별도 저장했다. 프로브 가열/입자 포집 근거 없이 관측
연산자를 바꾸지 않았으며, 농도 실측값을 분포 제약에 넣지도 않았다.
