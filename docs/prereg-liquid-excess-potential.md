# 질소·산소 액상 초과 Gibbs/혼합열 — 사전 계획 2026-09-06

NBS Report3921 (1955), printed p12 eq1a/b, p24 Table4, p25 Table6를
PDF43/77/79에서 직접 시각 확인했다. 세 온도 T=(65,70,77.5)K의
A=(1.47,1.38,1.22)cal/cm³, V_N=(32.58,33.40,34.73),
V_O=(25.32,25.82,26.58)cm³/mol를 사용한다. 기존 활동도 함수/기본판은
수정하지 않는다. 원문 PDF의 기존 해시를 검증한다.

## 선택형 후보와 제한

`gE=4.184*A*V_N*V_O*x*(1-x)/(x*V_N+(1-x)*V_O)` J/mol를 하나의
잠재함수로 사용한다. `sE=-gE_T`, `hE=gE-T*gE_T`, `CpE=-T*gE_TT`,
`muE_N=4.184*A*V_N*phi_O²`, `muE_O=4.184*A*V_O*phi_N²`이다.
상평형만 활동도로 바꾸고 열량을 이상혼합으로 두지 않는다.

세 표본의 최소 차수인 이차 보간을 명시적인 후보로 사용한다. 이는
원문에 없는 보간 선택이며 원문 측정 혼합열이 아니다. 동일 표본의 PCHIP
보간을 별도 민감도로 계산한다. 후자는 C1이므로70K의 CpE는 우측 곡률이고
좌우가 다를 수 있다. 이 차이를 숨기거나 허위 물리적 상전이로 부르지 않는다.
압력 독립 gE이므로 vE=0이다. 원문도 부피 가산성에 한계가 있음을
기술한다. 순수액체 체적은 기존 공통 G 모듈을 쓰고, 표의 V는 gE 상관식
내부의 체적분율에만 쓴다. 65--77.5K,0<P<=200kPa 밖은 거부한다.
H2는 불용성 이상 기체이며 혼합고체·용해·기체 초과 G는 포함하지 않는다.

## 구현/검증

- g=h-Ts, h_T=Cp, G_P=v, 조성 미분/부분몰 Euler/Gibbs-Duhem,
  순수성분 극한, 표 온도의 기존 활동도 재현, 양의 총 Cp/조성곡률 검사.
- 양의 비응축 기체가 있는 N2/O2 flash를 별도로 구현한다. 액체 안정성은
  전체 기체에 대한 접선평면 거리 최소값으로 확인하고, 성분량/화학퍼텐셜
  잔차와 독립 총 G 최소화로 검증한다. 확산 데이터는 매개변수 추정에 안 쓴다.
- 같은 기존 NBS9점을 동일 기체 모델로 이상/초과 G 비교한다. 같은 자료
  상관 재현이며 독립 검증이 아니다. 기체 비이상성과 혼합열 검증은 별도다.
- 이미 고정된356개 실제 국소 표본에서 65--77.5K 안만 같은 열량 장부로
  비교한다. 상분할과 혼합열 효과를 구분하고, 고정 h 온도는 근이 범위 안에
  있을 때만 구한다. 기존 필드 재생/새 ODE와 혼동하지 않는다.
- 새로운 Python/원문/선택JSON 해시를 고정하고 이전134파일 보존 확인.

   tetrafluoride*, J. Chem. Thermodyn.7(9),855--864,
   DOI https://doi.org/10.1016/0021-9614(75)90094-4.
