# PRESLHY 동시 열·성분 프로파일 모멘트 결과

Date: 2026-09-08

## 결론

PRESLHY Trial 10과 23의 공위치 수직 5점 원신호를 같은 시각에 맞춰
계산한 결과, **열적 온도결손 폭은 1.78 m에서 수소 폭과 거의 같지만
4.00 m에서는 더 넓어진다.** 두 시험의 제곱폭 성장비 중앙값도 각각
1.472와 1.450으로 같은 방향이다.

따라서 열폭을 수소폭보다 좁게 만드는 기존 연구 후보
`Sc_t/Pr_t=0.70/0.85=0.8235`를 PRESLHY 하류에 그대로 적용할 근거는
없다. 반대로 이번 값 1.45를 `D_h/D_C`로 채택할 수도 없다. 측정량은
엔탈피가 아니라 유한한 1 m 수직 구간의 온도결손이며, 밀도·상변화·
측방향 손실·비정상 이류가 포함돼 있기 때문이다.

모델 보완 방향은 폭 계수 조정이 아니라 **중심 엔탈피 진폭과 열의 2차
모멘트를 각각 보존 수송하는 경로**다. 이미 구현된 독립 열모멘트 상태를
이 관측 연산자로 검증해야 하며, 단일 `D_h/D_C` 변경만으로 중심 냉각
잔차를 고치지 않는다.

## 직접 절단 모멘트

각 시각의 비음수 스칼라 `phi`에 대해 측정된 수직 구간에서만

```
M0 = integral(phi dz)
zbar = integral(z phi dz) / M0
sigma_trunc^2 = integral((z-zbar)^2 phi dz) / M0
```

를 사다리꼴 적분했다. 가우시안 피팅, 외곽 꼬리 외삽, 모델 계수 피팅은
없다.

| trial | x (m) | 열 절단폭 중앙값 (m) | 수소 절단폭 중앙값 (m) | 동시 열/수소 폭비 중앙값 [IQR] |

| trial | 제곱폭 성장비 중앙값 [IQR] | 열 성장 +/비양수 | 수소 성장 +/비양수 |

분모가 작아지는 시각 때문에 성장비 IQR은 넓다. 음의 수소 폭 성장 9개를
절댓값으로 바꾸거나 버리지 않았다. 두 시험 모두 사전 지정한 공통지연과
최소 10쌍 기준을 통과했지만, 이는 계수 식별보다 **형상 방향의 반복성**을
보여 주는 결과다.

## 모델 결정

1. `D_h/D_C<1`인 기존 두-스칼라 후보를 PRESLHY 기본값으로 사용하지 않는다.
2. 이번 관측 성장비를 `D_h/D_C`로 피팅하지 않는다.
3. 독립 열모멘트 검증에서는 중심 엔탈피 진폭과 2차 모멘트를 함께 비교한다.
   폭만 맞고 중심 냉각이 사라지는 후보는 거부한다.
4. TKE/정상응력은 측정 속도 경계가 없으므로 별도 불확실성 구간으로 유지한다.
5. 다음 하류 후보는 동일한 원자료 관측 연산자를 사용하고, 모델 예측을
   동일 5점·동일 유한구간으로 투영해 비교한다. 관측에 가우시안 꼬리를
   추가하지 않는다.
