# 형상 보완 후 적분 진단 계획

2026-09-05. 원래 `edge_enrichment_screen_2026-09-05.json`은 0/7 통과이며
그 기록과 계산 코드를 수정하지 않는다. 3개 조건의 경계 개선은 독립 모멘트
검증을 통과하지 못했다. 다음은 결과를 본 뒤 추가한 **수치 진단**이다.

가우스 직교 적분으로 얻은 보존 오차가 실제 형상 변경의 결함인지, 검증
적분의 오차인지 분리한다. 원래 2차원 계수는 재적합하지 않는다.

사각 대칭으로 0<=phi<=pi/4의 1/8 단면만 적분한다. q=q0*(a²+b²),
a=sqrt(q/q0)*cos(phi), b=sqrt(q/q0)*sin(phi), 0<=q<=q0/cos²(phi).
전체 면적 적분은 `8*A*integral(dphi*integral(dq*integrand))`이다.
열 2차 모멘트의 대칭 평균 좌표는 `(sy²+sn²)*q`이다. 이 평균은
교환 대칭인 이번 스칼라/속도장에만 유효하다.

각 각도에서 새로운 C/H 형상으로 실제 상평형 역산을 수행한다. 이상온도
좌표 Ti와 Y의 모든 물성표 경계를 찾아 q 패널을 분할한다. 기존 가우스
단면의 반경 분할을 재사용하지 않는다. 표본에서 Ti 증가/Y 감소가 깨지는
경로는 이번 방법의 지원 범위 밖으로 거부한다. 이 표본 검사는 전역 증명이
아니다. 분할된 각 구간의 Gauss 적분과 각도 적분을 각각 세분화한다.

먼저 영 보정이 기존 셀분할 기준 여섯 모멘트를 재현하는지, 수정된 형상이
서로 다른 적분 차수에서 같은 값을 주는지 확인한다. 원래 모멘트 기준
1e-8과 인접 차수 차이 1e-5는 바꾸지 않는다. 필요 시 8/32,16/64,16/128
(패널/각도)까지 확인한다. 다른 수송장이나 물리 계수는 변경하지 않는다.

이번 추가 진단만으로 실패한 단면을 통과로 바꾸거나 하류에 연결하지 않는다.
만약 모멘트 보정이 실제로 필요하면, 셀분할 기반의 보존 재투영과 형상
제약 최적화는 명시적인 후속 실험으로 수행해야 한다.

실제 조건 진단 전 합성 시험에서는 각도32차의 영 보정 힘 오차 2.01e-7이
128차에서 2.64e-9로 감소했다. 단위시험의 검증 차수를128로 늘렸으며
기준1e-8은 유지했다. 실제 7조건에서는 각 조건의 독립 경계 최대 잔차가
가장 작은 완료 형상 하나를 진단 대상으로 선택한다. 이 선택은 후속 진단
비용을 줄이기 위한 것이며, 원래4/6차 결과를 삭제하거나 통과를 의미하지
않는다. 영 보정은16/128, 선택된 형상은8/32,16/64,16/128로 검사한다.
