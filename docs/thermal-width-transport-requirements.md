## 왜 경계 통과만으로 하류를 계산하면 안 되는가

현재 단면을 `rho_c, Y_c, A, theta, u_c, beta_H` 여섯 양으로 표현한다.
여기에 위치 x,z가 있다. 다섯 플럭스 수송식과 두 위치식만으로는 여덟 상태의
미분을 결정할 수 없다. 경계에서는 별도의 근접장 부력 F_b가 여섯 번째
제약을 제공하지만, 하류의 `dF_b/ds`는 아직 주어지지 않았다.

```
q = (rho_c, Y_c, A, theta, u_c, x, z, beta_H)
dF_mass/ds, dF_H2/ds, dP_x/ds, dP_z/ds, dE_total/ds = 기존 수송 항
dx/ds = cos(theta), dz/ds = sin(theta)
추가로 필요한 것: 열 형상 자유도의 독립 수송식 한 개
```

`d beta_H/ds=0`을 놓는 것은 새 가정이며, 경계 결과에서 따라오지 않는다.
`dF_b/ds=0`도 옳은 보존식이 아니다. 따라서 새 경계 클래스는 하류 `solve`,
미분/소스 평가 및 센서 예측 사용을 명시적으로 거부한다.

## 구현 후보: 엔탈피의 2차 단면 모멘트

가능한 여섯 번째 수송량은 중심에서 떨어진 위치에 열이 얼마나 분포하는지를
표현하는 `M_h,2 = integral(r_perp^2 * J_s) dA`이다. J_s는 단면을 통과하는
전체 엔탈피 플럭스 밀도이며, 평균 대류 H*u와 필요한 난류/분자 플럭스를 포함한다.
단위는 W·m²이다. 코드에서는 `enthalpy_second_moment`라는 이름을 사용한다.

국소 직선 좌표, 고정 단면 영역에서
`partial_s J_s + div_perp J_perp = S_H`를 가정하면 부분적분으로:

```
d/ds integral(r_perp^2 J_s) dA
  = 2 integral(r_perp dot J_perp) dA
    + integral(r_perp^2 S_H) dA
    - boundary_integral(r_perp^2 J_perp dot n) dl
```

위의 단순 항등식 자체는 **현재 곡선·변형 단면에 바로 적용할 구현식은 아니다**.
후속 연산자에서 곡률의 계량 인자와 비등방 폭의 경계 이동 항을 포함한
평면 곡선/사각 단면의 식을 별도로 유도·시험했다. 지면 절단과 비틀림,
바람에 의한 실제 횡방향 유량 분포는 아직 포함하지 않는다.
경계 항을 자동으로 0으로 놓지 않는다.

필요한 폐쇄 항은 다음과 같다.

- 횡방향 평균 이동과 난류 열 플럭스 J_perp. 기존 총 유입량만으로 이 공간
  분포가 유일하게 정해지는 것은 아니다.
- 열 확산은 단위질량 엔탈피/온도 구배와 성분 확산을 고려해야 한다.
  `rho*h`의 구배를 그대로 단순 열전도로 취급하지 않는다.
- 총에너지와 평균 운동에너지/TKE 사이의 교환을 중복 계산하지 않는다.
  상평형 표에 이미 포함된 잠열을 외부 열원으로 한 번 더 더하지 않는다.
- 새 난류 확산률이나 Pr/Sc를 쓸 경우 원래 적용 조건과 유효 범위를 확인하고,
  이번 PRESLHY 온도나 폭에 사후 맞추지 않는다.
