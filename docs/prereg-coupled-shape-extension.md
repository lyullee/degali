# 동시 초기화의 나머지5개 조건 확장

2026-09-06. 실행 전 명세. 파일럿25/11은 통과했고 그 기록을 유지한다.
시험10/12/22/23/24를 모두 수행한다. 원래7개 중 남은 전체 집합이며
실측 점수에 따라 조건을 추가/제외하지 않는다. 그룹을 나눠 실행해도 된다.

물리식/목적함수/제약/검증은 `prereg-coupled-shape-initialization.md`와
정확히 같다. 초기값은 기존 고정 수송장 단면 기록에서 가져온다.
시험10은 원래 차수6(37상태/35활성 변화율), 나머지는 차수4(23/21).
시험 결과를 보고 차수나 물리 계수를 조절하지 않는다.

공통32차 혼합 입력, 비율1, 반경 질량·운동량 보존 유량, 즉시 전단 열전환,
6개 모멘트, log 형상±0.1, 반복망4/24 최대6회→8/48 최대3회 그대로다.
수치 목적함수의4% 목표와 독립 수소/열/운동량5% 기준도 바꾸지 않는다.
독립 모멘트8/8 및16/16, 수송4/8 및8/16,65각도/반경16차와129² 물성
검사, 양의 표본 chi_P/면 유입/곡률×반폭<0.1를 동일하게 적용한다.

확장 코드의 차이는 기존 계산을 재사용하는 실행 함수 분리, 선택 집합,
진행 단계/프로세스 기록뿐이다. 기존 파일럿 소스/명세는 수정하지 않는다.
차수6 연산자가 별도 정밀 연산자와 일치하는 단위시험을 먼저 수행한다.

통합 결과는 기존 파일럿과 신규5조건의 정확히 한 번씩의 집합을 검사한다.
실패도 모두 남기며 통과 조건만으로7/7이라고 보고하지 않는다.
전체가 통과하지 않으면 실패 이유를 먼저 분석한다. 새 가정/수치 보완을
시험할 경우 별도 후속 명세와 기록으로 분리한다.

하류/실측 계산은 이번 확장 판정에 포함하지 않는다. 국소 초기화의 성공은
새 상태의 전체 확산 모사나 관측 정확도 개선을 입증하지 않는다.
