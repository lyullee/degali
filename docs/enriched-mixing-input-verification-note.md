# 혼합률 입력의 별도 정밀 검증

2026-09-05. 첫 수송 예비 실험10에서 혼합률 입력의8/16차 상대 차이는
1.5573e-5로 원래1e-5 기준을 조금 넘었다. 원본 실패는 수정하지 않는다.
실제 모드 변화율/행렬/유한차분은 더 작은 오차를 보였지만, 입력 정밀도를
별도로 확인해야 한다. 이 문서는 결과를 본 뒤의 추가 수치 검사다.

동일7개 원래 약형 혼합률을 셀별16/32차로 보간하고 각 셀의
정규화 위치0.08,0.31,0.67,0.94에서 직접 원래 수식과 비교한다.
이 표본은 원래 보간 노드와 최초0.17,0.43,0.79 검사 표본과 다르다.
16/32차 사이 및 각각 직접 수식과의 상대 차이가1e-5 이하인지 확인한다.
혼합률을 맞추는 새로운 물리 계수나 관측 자료는 사용하지 않는다.

통과하면 현재 수송 계산의 정밀16차 입력만 별도 검증된 것으로 기록한다.
원래8/16 비교 실패는 유지하며, 나머지 수송/물성/경계 실패를 대신 통과시키지
않는다. 통합 수치 판정은 원래 정밀 변화율·행렬·유한차분 검사와 이 별도
입력 검사를 모두 만족하는 경우에만 구분해서 보고한다.
