## 무엇을 구분했는가

현재 pressure-loss density CONTROL에서는 시험10/23의 차가운 중심부 일부를
센서 위치 차이만으로 설명할 수 없다. 시험23의1.19m는 원래 단면에서
어느 위치를 보아도 관측 **중앙값보다29.942K** 따뜻하다. 최저값이 아닌
중앙값으로도 남는 차이다. 다만 전체 잔차가 같은 원인이라는 뜻은 아니다.

사전 방법은 `prereg-downstream-cold-envelope.md`, 실행 도구는
`tools/audit_downstream_cold_envelope.py`, 결과는
`reference/preslhy/downstream_cold_envelope_2026-09-06.json`이다.
입력 해시, 원래4궤적의 온도·5플럭스·농도 재생,1차134파일/런타임 확인.
원래41센서×유량 가정2개=82행 누락0, 계산22단면 모두 완료했다.

지면 반사를 한 번 포함한 단면에서 Gaussian 형상의 최댓값을 구하고
물성까지 평가했다. 모든 실제 단면에서 표본 온도는 형상값에 대해 단조
감소했다.257→1025점 및 국소 최소화로 최저T 변화는0이다. 이것을 임의의
혼상 EOS에 대한 수학적 전역 최소 보증으로 확대하지 않는다.

독립 형상 함수의 격자 대조, 대칭/모드 경계/극한, 비물리 반사 상태 거부,
비단조 제조 온도의 내부 최소 등 새21검사 통과. 관련8모듈 합계197검사
통과(3.20초)이며 전체 역사적 프로젝트 회귀를 새로 돌렸다는 뜻은 아니다.

## 다음 물리 작업의 범위

1. 실제 오차를 움직이지 않은 이상혼합 액상 후보의 긴 재실행은 중지한다.
   시험10의 새 액상 실제 계산은 완료/미채택이고, 시험23의59--63K 혼합상
   미지원은 별도 문제로 보존한다.
2. 기하 위치만 옮기거나 항력만 더하는 후보를 이 근접장 냉각의 해결책으로
   제시하지 않는다. 중심 열상태/독립 열·성분 수송 또는 상류 에너지 분배가
   실제로 바뀌어야 한다. 전체 기하 수송을 바꾸면 중심 물성도 변하므로
   **모든 기하/유입 물리**를 배제한 결과는 아니다.
3. 다음 독립 항목은 실제 필드 에너지 규모 진단이다. 새 TKE 상태를 계속
   늘리기 전에 현재 각 단면의 평균KE/열 플럭스, 초기 기계 에너지와 센서
   온도 간격에 해당하는 열량 규모를 분리한다. 현재 위치의 KE만으로
   상류에서 저장되어 이동한 TKE의 상한을 단정하지 않는다. 실측T를 맞추는
   k나 임의 소산상수는 추정하지 않는다. 기존 합성TKE 검사는 반복하지 않는다.
4. 혼합 공기 입자의 유한속도 문제는 기존 `finite-rate-sublimation-audit.md`의
   입자 크기/핵생성 면적 미확보를 유지한다.1/10/100um 민감도나 LH2의
   이미 완료된0.782--2.011um 지연 선별을 동일하게 반복하지 않는다.

진단은 새 하류 모델 구현이나 개선 점수가 아니다. 확인한 근접장 중심 잔차,
축외 잔차, 정상/시간통계 차이를 나눠 후속 모델을 선택하기 위한 근거다.
