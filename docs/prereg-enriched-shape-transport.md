# 보완 단면의 결합 수송 변화율 — 계산 전 명세

2026-09-05. 기존7개 통과 단면과 코드/실패 기록을 유지한다. 이번에는
옛 질량 유량/응력 일을 고정하지 않고 새 형상의 보존 변화율로 다시 만든다.
하류 적분이나 실측 점수 계산에 앞선 **조건부 국소 수송식 검증**이다.

## 중복 상태 제거

열 형상 기저에는 q=q0(a²+b²)가 정확히 포함된다. 그러므로 기존
gamma=dlog(beta)/ds의 열 변화2*q*H/beta²는 열 형상 계수 변화로도
표현된다. 둘을 함께 미지수로 두면 게이지 중복이다. beta_ref는 기저의
기준값으로만 고정하고 실제 열 폭 변화는 q 열 모드가 담당한다.
상태는 log(rho_c),log(Cc),log(A),theta,log(uc),x,z와 C/H 형상 계수다.
시험10은37개, 나머지는23개다. x,z 두 변화율은 방향에서 정한다.

## 명시적인 수송 가정

q,phi마다 보존 질량/축운동량 유량이 정규화 반경 방향을 향하는 축약
가정을 사용한다. f가 각도에 의존해도 div((xi,eta)*f)=2*f+2*q*f_q다.
이는 무회전 조건이 아니며 무발산 횡 흐름의 자유도를 포함하지 않는다.
물리 단면의 크기 변화/곡률은 기존 ALE 좌표식으로 복원한다.

```
B_M = partial_s(A*rho*u), B_P = partial_s(A*rho*u²)
f_M = -integral_0^q B_M dq/(2*q)
f_P = integral_0^q (A*b_s-B_P) dq/(2*q)
b_s = g*(rho_a-rho)*sin(theta)
R_P = f_P-u*f_M
P_A = -2*q*u_q*R_P
f_K = u*f_P-.5*u²*f_M
```

기존 축약 부력-일 규약과 전단 생성의 즉시 열전환 가정을 명시적으로
유지한다. 총에너지 원항에는 integral(u*b_s)dA를 한 번만 더한다.
전단 생성을 총에너지에 다시 더하지 않는다. 완전한 RANS/TKE/압력 모델은 아니다.

수소 혼합률 chi_C(q)는 **외부 제공이 필수**다. 이번 최초 단면 검사에서는
기존 통과 약형 상태의 양의 chi_C를 입력으로 제공한다. 새 밀도/열 형상에서
f_M,f_P,f_K와 전단 생성은 다시 계산하며, 치환하지 않는 것은 이 혼합률
입력뿐이다. 이를 새 형상에서 유도된 보편 혼합 폐쇄식이라고 부르지 않는다.
chi_C 표는 기존 상평형 셀별 Legendre 보간으로 만들고 차수 증가를 확인한다.
이 불연속 구간도 새 반경/각도 적분에 함께 분할한다. 열/성분 비는 명시적1이다.

a,b에서 J=2*q0*A, W_M=2*q0*(a,b)*f_M이다. 실제 스칼라 플럭스는
각도 성분을 포함한다:

```
W_C = Y*W_M - A*rho*chi_C*grad_ab(Y)
W_H = h*W_M - A*rho*chi_C*grad_ab(h), h=H/rho
```

수소/열의 각 기저 psi_i에 대해 약형 수송식을 적용한다:

```
d_s integral(J*C*u*psi) = integral(grad(psi)·W_C)
d_s integral(J*H*u*psi) = integral(psi*P_J + grad(psi)·W_H)
                             - boundary_integral(psi*W_H,res)
W_H,res = (u_a²/2)*W_M - W_K, W_C,res=0
```

주변 유입의 일반적인 플럭스 조건 근거:
[성분](https://doc.comsol.com/6.3/doc/com.comsol.help.cfd/cfd_ug_chemsptrans.11.139.html),
[열](https://doc.comsol.com/6.4/doc/com.comsol.help.heat/heat_ug_theory.07.009.html).
이 자료가 현재 액화수소 모형이나 반경 유량 가정을 검증하는 것은 아니다.
다섯 전체 보존식과16/30개 모드식을 함께 선형화해21/35개 변화율을 푼다.
새 형상 계수의 변화율을0으로 두지 않는다. 경계 조건은 이 단계에서 약형이며
점별 구성식 잔차를 독립적으로 평가한다.

## 수치 및 판정

- 합성 시험: 열 폭 게이지 동일성, 실제 필드/모멘트 미분, 패널 내부 누적
  적분과 제조해의 국소 발산, 운동에너지/응력 일의 곱 미분 항등식.
- 실제7조건: 8차 및16차 혼합률 보간, 새/옛 셀 교차를 나눈 적분4/8,
  필요 시8/16차(반경/각도). 조립 행렬, 해의 변화율과 실제 모멘트의 독립
  유한변화 검사 기준1e-5. 선형화 잔차1e-8. 영차 열수지도 별도 확인한다.
- 원래 상평형 표는 수정하지 않는다. 게이지 중복이나 불량 계수 행렬을
  의사역행렬로 감춰 임의의 변화율을 선택하지 않는다.
- 새 f_M의 면 유입, 유한/비음수 chi_P, 곡률 반폭<0.1을 검사한다.
- 새 수송장의 독립 면 표본에서 수소/열/운동량 점별 잔차를 기록한다.
  기존 경계5% 통과가 유지되는지도 검사한다. 실패하면 약형 계산의 성공과
  분리하며 짧은 하류 구간 또는 기본 모델로 승격하지 않는다.
- 아직 혼합률의 하류 갱신 법칙은 없다. 이번 해는 주어진 혼합률 입력에
  조건부다. 초기 변화율을 구한 것만으로 전체 하류 모델 완성을 주장하지 않는다.
