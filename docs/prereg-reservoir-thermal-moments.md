# 주변 저장 영역과 열 모멘트의 유입 플럭스 연결 — 계산 전 명세

2026-09-05. 이전 7개 열수지 실패를 보존한다. 이번에는 **다른 경계 조건을
갖는 저차 약형 모형**을 시험한다. 내부 Gaussian 구배가 이 경계 조건을
점별로 만족한다고 주장하지 않는다. 기본 DEGADIS나 이전 결과는 변경하지 않는다.

## 경계 조건과 물리 범위

[COMSOL의 Danckwerts 유입 설명](https://doc.comsol.com/6.4/doc/com.comsol.help.heat/heat_ug_theory.07.009.html)은
유입 온도를 강제하기보다 상류 유체가 가져오는 엔탈피 플럭스를 지정한다.
[성분 유입 조건](https://doc.comsol.com/6.3/doc/com.comsol.help.cfd/cfd_ug_chemsptrans.11.139.html)도
상류 농도와 질량 유입으로 총 성분 플럭스를 정한다. LH2에 대한 검증은 아니다.
여기서는 평균 운동에너지와 응력 일을 따로 운반하므로, 아래의 총에너지
경계 조건으로 확장하는 것은 이번 축약 모형의 명시적 가정이다.

기존 변형 정규화 좌표의 방사형 질량 플럭스 f_M, 평균 KE+응력 일 f_K를 쓴다.
주변 기준 엔탈피 h_a=0, 수소 Y_a=0, 주변 수평 풍속 u_a를 지정하면:

```
e_a = h_a + u_a²/2
f_E,b = e_a * f_M
f_H,b = f_E,b - f_K
f_C,b = Y_a * f_M = 0
```

질량 유입인 면에서만 적용한다. 외향 질량 플럭스가 생기면 무단으로 주변
상태를 유출에 적용하지 않고 지원 밖으로 중단한다. 위 f_H,b는 0인 주변
엔탈피를 경계 온도로 덮어쓰는 것이 아니다. 경계의 평균 KE/응력 일과
유입 총에너지의 차를 일관되게 배분한 플럭스다.

내부 열 플럭스는 기존 질량당 엔탈피 구배와 명시적 D_h/D_C=1을 유지한다.
열 0차/2차 모멘트의 **경계 적분에만 지정된 유입 플럭스**를 쓴다.
이는 Neumann형 자연 경계 조건의 가중 잔차 근사다. 내부 구배의 경계 값과
지정값 차이를 0으로 만들지 않으며, 그 차이와 성분/운동량 경계 차이를
기록한다. 큰 점별 결함을 수지 통과나 실측 검증으로 포장하지 않는다.

## 기계적 에너지 장부를 명시적으로 맞춤

이전 축약 운동량식은 b_s=g(rho_a-rho)sin(theta)를 쓴다. 그에 대응하는
일 W_b=integral(A*u*b_s)는 평균 KE 식에 존재한다. 이번 **축약 부력-일
규약**에서는 총에너지 원항을 기존 u_a²*M'/2에 W_b를 더한 것으로 정의한다.
P를 총에너지에 다시 더하지 않는다. 열원 Q=P는 기존 국소 평형 가정이다.

이 변경은 열수지 잔차를 피드백하는 보정이 아니다. W_b는 상태에서 직접
계산하며 이전 원항과 차이를 별도로 기록한다. 완전한 가변밀도 RANS의
정압 엔탈피/중력 위치에너지/주변 정수압 일을 닫은 모델로 해석하면 안 된다.
[RANS 에너지식](https://tmbwg.github.io/turbmodels/implementrans.html)의 응력 일과
TKE 항은 여전히 별개다. 이번 규약은 호출 시 명시해야 하며 기본 모델에는 없다.

질량·수소·벡터 운동량 원항은 유지한다. 부력 적분만 기존 텐서 적분 대신
같은 상평형 셀 분할로 평가하고 초기 값의 재생 정확도를 검사한다.

## 열 폭 및 수지

새 5개 원항에 대해 `t=a+gamma*b`인 기존 미분 집합을 구한다. 열 2차
모멘트 약형의 경계 항을 위 f_H,b로 바꿔 gamma를 푼다. 전체 열수지는
에너지/KE 식에서 자동으로 일관되어야 한다. 따라서 그 작은 잔차 자체는
독립적인 물리 검증이 아니라 **구현 일관성 검사**라고 보고한다.

별도로 실제 플럭스/M2의 변화 전후 차분, 독립 사각형 경계 적분, 합성 해,
하류 간격 수렴을 검사한다. 추가 계수 적합, delta 변경, 경계 온도 덮어쓰기,
초기 6개 모멘트 재적합은 하지 않는다. beta_H를 고정하지 않는다.

## 계산 전 게이트

- 기존 코드/입력 해시 유지. 실제 소스 재생 1e-8, 초기 6개 모멘트 1e-9.
- 상평형 셀 분할 8/16차의 수지 성분 차 <=1e-5 (분모 max(abs(fine),1)),
  5개 미분 원항 잔차 <=1e-8, 열 약형/KE/유입 장부 <=1e-5.
- 각 평가에서 q 표본 257개와 상평형 셀 중점에서 수소/전단 혼합률 >=0.
  경계 q0~2q0 표본 129개에서 f_M<0. 곡률×반폭<0.1.
  표본 검사는 전 반경 보장이 아니다. 분기/물성 역산 실패는 중단한다.
- 초기/종점은 더 조밀한 1025개 표본으로 재확인한다. 실제 플럭스 차분
  간격은 (2e-4,1e-4)/max(norminf(t),1) m, 플럭스/1m 정규화 차 <=1e-5.
- 초기 약형 게이트 통과 시 **연구용 짧은 구간만** 진행한다.
  길이는 min(0.01 m, 0.05*min(sy,sn)). 중점 RK2를 2/4/8분할로 실행한다.
  상태와 5개 원항 및 물리 M2 원항을 함께 적분한다.
  4/8 분할 종점 로그상태 차 <=1e-5, 8분할 플럭스/열 M2 수지 <=1e-5.
  상대 변화의 1차 척도는 초기 각 플럭스(질량 최소 1e-12, 에너지/M2 최소1)다.
- 점별 경계 구배 결함은 줄었다고 가정하지 않는다. 이 저차 단면의 공간
  정확도를 검증하기 전에는 현장 38/17/41 센서 계산이나 기본 승격을 하지 않는다.
