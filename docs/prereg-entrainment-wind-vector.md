# 관측 풍향의 성분별 유입 수지 — 2026-09-06

좌우/풍향 원자료 감사가 끝난 후 만드는 기계적 일관성 검사다. 시험10의
같은49표본 평균 속도는 분사축/오른쪽=[1.790904,.698400]m/s, 시험23의
1Hz 풍향은 원문 고장으로 제외했다. 근거리5분 기록은 별도 유효 시각으로
그대로 유지하며, 온도에 맞춰 관측소/시간/각도를 선택하지 않는다.

선택형 기초 연산자로 dM/ds=m일 때 유입 성분 유량을
[m,0,m*Wx,m*Wy,m*Wz,m*(ha+|W|²/2)]로 구현한다. 이 식은 주변 공기가
운반해 들어오는 질량/수소/3방향 운동량/총에너지이며, 항력·압력일·난류
수송 또는 완성된3D플룸 방정식을 대체하지 않는다. ha는 명시 입력으로
받아 엔탈피 기준변경도 추적한다. 기존 소스기본값/134파일은 변경하지 않는다.

동일 CONTROL10/23의 실제 저장된 질량 유입률과 평균풍속 높이 보정을
유지한 채 관측 방향만 바꾼 단위 진단을 한다.10의 원거리49점 속도벡터
평균 방위 및10/23의 근거리 각5분 기록 방위를 각각 분리한다. 자료가
같은 방향을 두 시각에 줬더라도 입력 행을 보존한다. 풍속 크기를 고정하므로
운동량 방향만 바뀌고 유입 운동에너지는 같다. 역방향 성분도0으로 자르지 않는다.

방향에 따른 유입 운동량 차이를 기존 저장 arc_length로 적분하고 원래
단면 운동량 크기로 나눈다. 원래와 같은 방향에서는 기존 주변공기 유입
성분을 정확히 회복해야 한다. 같은 크기의 에너지 변화0, 회전공변성,
엔탈피 기준변경,0질량유입을 검사한다. 저장노드 절반 적분 차이도 보고한다.
기존 항력·연행률·온도·단면폭·경로는 이 감사에서 재계산하지 않는다.
누적 운동량으로 정의한 방향은 실제 새 제트 궤적 예측으로 부르지 않는다.

이 감사는 누락된 횡방향 강제의 필요성과 규모를 식별하는 것이다.
유입풍속의 단순 축 투영만 넣고 횡운동량/3D경로를 버리는 ‘수정’은 하지
않는다. 후속3D후보는 원래 대칭평면 극한/6플럭스 접속/공간상태 해상도/
원래 관측점 좌표 평가를 함께 통과해야 한다. 시험23의 고장자료를
복원한 것처럼 처리하거나 관측값으로 제트 편향각을 피팅하지 않는다.
