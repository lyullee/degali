# 열/성분 분리 수송의 기준 일관성 보완 —2026-09-06 11:27KST

## 구현 완료

선택형 `src/degali/addons/species_carried_enthalpy.py`에 유효 이성분
총 엔탈피 확산 유량을 구현했다. `prereg-species-carried-enthalpy.md`의
사전 식 그대로이며 새로운 확산률·Pr/Sc·초기 난류 기본값은 만들지 않았다.
rho,DY,DT,grad(h),grad(Y),h_Y를 모두 명시적으로 받는다.

```
jY = -rho*DY*grad(Y)
J_heat = -rho*DT*(grad(h)-h_Y*grad(Y))
J_carried = h_Y*jY
J_H = J_heat+J_carried
```

상대 성분의 질량유량은 -jY다. 성분이 지닌 엔탈피는 추가 외부 열원이
아니며, 열만의 유량과 구분한다. DY=DT일 때 기존 -rho*D*grad(h)로
부동소수점 오차 안에서 정확히 돌아간다.

## 왜 필요한가

성분별 엔탈피 기준을 바꾸면 h'=h+aY+b이다. 같은 물리 흐름의 유량은
J'_H=J_H+a*jY로 변해야 하며, 에너지 상태와 성분 수송을 함께 갱신한
후의 T는 변하면 안 된다. 단순 -rho*DT*grad(h)만 쓰면 DY!=DT에서 이
조건을 어긴다. 새 식은 기준변경에 따라 함께 변하는 h_Y를 포함해 이를
보완한다. 등온 조성 혼합에서 열만의 유량은0이고 성분 엔탈피 이동만
남아야 한다는 극한도 만족한다.

관련 기존 위치는 `thermal_moments.py:eddy_enthalpy_flux`,
`transverse_mixing.py:physical_transport`의 h구배 항 등이다. 후자를 포함한
최신 실제 약형/TKE 시도에서는 열/성분 비1을 사용했으므로 새 항의 차이는
0이다. 기존1차 및 그 결과를 오류로 무효화하는 변경이 아니다.
비1인 후속 후보에 이 단순 h구배식을 그대로 쓸 수 없다는 구현 조건이다.

일반 에너지/성분식의 결합은
[Cantera 에너지 식](https://www.cantera.org/3.2/reference/onedim/discretization.html)에
확인된다. 위 두 유효 확산률의 이성분 표현은 본 프로젝트의 유도이며,
이 문서가 액화수소 혼상에서 그 값을 검증해 준다는 뜻은 아니다.
