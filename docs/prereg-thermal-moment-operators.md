# 열 형상 수송 연산자 — 계산 전 고정 명세

2026-09-05. 이 단계는 하류 폐쇄식 전체가 아니라, 그 식에 필요한 모멘트와
열 이동 연산자를 구현한다. 기존 7개 경계 상태와 실험 점수는 변경하지 않는다.

## 수송량과 좌표

`H=rho*(h-h_a)`이며 현재 상평형 표는 `h_a=0`이다. 우선 구현하는 양은
평균 대류 기여 `M2 = integral((y²+n²)*H*u) dA` [W m²]이다.
축방향 난류 엔탈피 플럭스까지 포함한 전체 열 모멘트라고 부르지 않는다.

JETPLU 적분의 변환 좌표는 `y=sqrt(pi)/2*sy*a`, `n=sqrt(pi)/2*sn*b`,
`a,b in [-delta,delta]`이다. 따라서 실제 적분 경계는
`|y|<=sqrt(pi)/2*delta*sy`, `|n|<=sqrt(pi)/2*delta*sn`이다.
기존 유입량 계산용 타원 둘레와 이 사각 적분 영역을 혼동하지 않는다.
`q=y²/(2sy²)+n²/(2sn²)`, `A=sy*sn`, `G=exp(-q)`이다.

평면 곡선 중심선의 접선/법선 좌표에서 곡률을 kappa, 계량 인자를
`m=1-kappa*n>0`으로 둔다. 지면 절단, 비틀림, 단면 회전은 이 구현 범위 밖이다.
주어진 물리 플럭스와 원항에 대한 보존식과 이동 경계 모멘트 항등식은:

```
partial_s Js + partial_y(m*Jy) + partial_n(m*Jn) = m*S
dM2/ds = integral(2*(y*Jy+n*Jn)*m + (y²+n²)*m*S) dA
          - boundary_integral((y²+n²)*m*Jperp dot outward_normal) dl
          + boundary_integral((y²+n²)*Js*v_boundary dot outward_normal) dl
v_boundary = (y*dlog(sy)/ds, n*dlog(sn)/ds)
```

これは与えられたフラックスに対する独自の座標変換/部分積分であり、
横流れ、乱流、運動エネルギー交換の分布を決定する新しい物理閉鎖ではない。
未指定の項を既定値ゼロとして埋める下流ソルバーは追加しない。

## 熱の勾配

独立に試す乱流勾配拡散の成分は `Qperp=-rho*D_h*grad(h)`。
`-D_h*grad(H)`ではない。D_hは未選定。実ケースでは **D_hで割った応答**
のみを計算し、D_h=1 m²/sを採用した物理予測とはしない。
これは分子熱伝導則でも、不等拡散・液滴すべりのモデルでもない。

同じ相平衡表で `C_q=-C`, `H_q=-H/beta_H²`,
`rho_q=(H_q-H_C*C_q)/H_rho`, `h_q=(H_q-h*rho_q)/rho` とする。
潜熱を別の原項として足さない。等圧相平衡という現在の仮定は維持する。
総エネルギーの積分収支だけから、その運動/内部エネルギー交換の空間
2次モーメントを推定することもしない。

根拠: [Turbulence Modeling Resource の RANS エネルギー式](https://tmbwg.github.io/turbmodels/implementrans.html)
は熱フラックスと応力仕事、乱流エネルギー輸送を別項として記述する。
同ページの空気向け定数や完全気体 EOS を LH2 混相に移植しない。
質量当たりエンタルピーによる一般化と上記の曲線座標変換は今回の明示的な
研究仮定/導出であり、この出典が LH2 への妥当性を保証するわけではない。

## 計算前の試験条件

- 有限矩形 Gaussian の解析 M2 と積分値: 相対 1e-10。
- 固定 H2 フラックスの縮約 M2 微分: 表の節点を避けた差分と相対 5e-5。
- 一定密度・既知 Gaussian 拡散解: 固定/拡大/縮小矩形の M2 差分と
  全項付き収支の正規化差 1e-7。境界熱流と境界移動を別々に記録。
- 曲率を持つ製造解: 原項込みの移動矩形収支と差分の正規化差 1e-7。
- 一定 h で rho だけ変わる場合の熱流はゼロ。相平衡状態の h_q は
  節点を避けた独立差分で確認。無効な密度、拡散率、座標は拒否。
- 固定7境界: M2 と解析式の相対差 1e-10。単位拡散応答は GL と独立
  適応 GK21 の差を `max(abs(reference),1)` で正規化して 1e-5 以下かを
  各項ごとに確認。失敗を隠さず、実験誤差やハンドオフ不合格とは区別する。

この段階で下流7ケースの ODE や38/17/41実測比較は行わない。
次段階は横方向平均移動・D_h・機械的交換の形状と地面境界を閉じること。
これらが定まる前に beta_H 一定または F_b 一定で進めてはならない。
