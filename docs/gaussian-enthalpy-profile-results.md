# 체적 엔탈피 분포 후보의 전체 비교 — 2026-09-05

## 결론

수소 질량과 체적 엔탈피에 같은 가우스 분포를 적용하는 연구 후보를 구현하고,
7개 접속, 전체 38개 농도 단면/17개 수직 프로파일, 동일 41개 온도 센서까지
비교했다. **최저온도 기준 MAE는 약 5% 줄지만, 중심 높이와 시간 중앙값 기준
온도 오차는 커진다. 기본 모델로 승격하지 않는다.**

대조군은 직전의 주변 상평형 일관성 수정 경로다. 원래 DEGADIS 기본 경로와
이전 결과는 보존했다. 이번 후보는 `downstream_thermodynamic_profile="enthalpy"`로
명시적으로 선택해야 한다. 모델 전체의 현장 검증 완료나 SCI 논문 수준의
독립 검증 완료를 뜻하지 않는다.

## 구현한 물리 가정

[사전 등록](prereg-gaussian-enthalpy-profile.md)대로 근접장, HEM 소스 에너지,
normal-H2, 실제 풍속/RH, 상평형 표, 접속 위치와 유입 계수는 유지했다.
하류에서 밀도에 가우스 분포를 강제하는 대신 다음을 적용했다.

```
C(r) = rho(r)*Y(r) = C_c*G(r)
H(r) = rho(r)*(h(r)-h_a) = H_c*G(r)
u(r) = u_a*cos(theta) + u_c*G(r)^(1.16^2)
```

국소 C,H로부터 기존 상평형 표의 밀도, 조성, 온도를 함께 역산한다.
같은 폭의 C,H는 이 연구의 **검사 대상 가정**이지 저온 다상 수소의 검증된
법칙이 아니다. 대조군의 일곱 조건도 속도 폭비는 모두 1.16이므로 이 비교에서
속도 폭비가 바뀌지 않았다. 관측값으로 계수나 열 폭을 맞추지 않았다.

밀도 분포가 더 이상 가우스가 아니므로 다음도 함께 바꿨다.

- 수소 유량식으로 중심 조성을 제거하고, 밀도·단면적·속도를 질량·운동량·에너지에
  맞추는 전용 하류 역산을 구현했다. 최종적으로 다섯 플럭스를 모두 검사한다.
- 부력은 실제 국소 밀도로 단면 적분한다. 밀도 가우스 전용 해석식을 재사용하지 않는다.
- 관측 위치의 온도와 농도도 같은 국소 상태를 사용한다. 실제 센서 위치와 이동하는
  플룸 중심을 혼동하지 않는다.
- 보간표 밖의 해는 거부하고, 주변/희석 극한과 기존 상평형 표 왕복을 시험했다.

## 수치 검사와 한계

첫 텐서 적분에서는 에너지만 수렴해도 질량·운동량이 수렴하지 않는 문제가
발견됐다. 해당 하류 실행은 결과 저장 전에 중단했으며,
[수정 이력](enthalpy-profile-quadrature-note.md)을 따로 남겼다.
유한 정사각형의 모서리까지 보존하는 정확한 극좌표 변수 변환으로 재계산했다.
물리 영역이나 허용오차를 넓히지 않았다.

| 검사 | 최종 결과 |
|---|---:|
| 접속 승인 | 7/7 |
| 접속 최대 상대 플럭스 잔차 | 1.660e-15 |
| 접속 최대 H2 질량밀도 반폭 차 | 1.517% |
| 접속 최대 중심 온도 차 | 1.42114 K |
| 접속 적분 차수 | 128–512 (각 극좌표 구간) |
| 하류 최대 상대 보존 잔차 | 4.500e-8 |
| 63개 저장 단면의 1배→4배 차수, 다섯 플럭스 최대 변화 | 2.985e-6 |
| 다섯 플럭스의 고정 적분 수렴 기준 | 1e-5, 통과 |

추가 부력 진단에서는 시험 22의 x=2.116 m에서 128/256/512차 값이
0.63817164 / 0.63815961 / 0.63816135 N/m였다. 최대 절대 차는
1.029e-5 N/m(해당 부력의 약 0.00161%)다. 이것은 다섯 플럭스의 사전 승인
항목과 별도의 진단이며, 모든 부력 적분이 1e-5의 같은 수치 기준을 통과했다고
표현하지 않는다. 이후 부력 모멘트 후보에서는 이를 독립 수렴 항목으로 다뤄야 한다.

짧은 구간의 0.01/0.005 m 간격 비교와 보존성은 단위시험을 통과했다.
이번 전체 실험은 최대 간격 0.02 m로 계산했다. 일곱 조건 전체의 0.01 m
재적분은 실시하지 않았으며, 보존 잔차와 전체 공간 간격 수렴을 동일시하지 않는다.

## 다음 보완의 구체적 대상

중심 온도와 다섯 플럭스가 가까워도, 단면 부력은 같지 않다.
예를 들어 시험 10 접속에서 근접장 부력은 0.017800 N/m인데 후보는
0.074164 N/m이다. 시험 23의 음의 부력도 -0.036970→-0.009669 N/m로
약해진다. 이는 중심 온도만 맞추는 열 형상 검사가 놓치는 항목이다.

이번 결과는 **동일 폭 C/H 가정만으로 열과 상승 오차를 동시에 해결할 수
없음**을 보여준다. 모든 열 프로파일이나 난류에너지 모델이 실패했다는 뜻은 아니다.
다음 단계는 근접장에서 전달되는 부력 모멘트까지 확인하면서 열 형상의 독립
상태와 수송식을 설계하는 것이다. 단면 열·질량 폭이나 난류 수송 계수를
관측에 사후 맞추지 않고, 부력·열·농도 검사를 함께 사전 고정해야 한다.
혼합물 실기체 EOS와 새로운 TKE 수송식은 이번에 구현하지 않았다.

병합 파일은 입력 분할 파일의 해시를 연결하며, 다른 열 프로파일이나 적분 방식의
분할 결과는 병합을 거부한다. 온도 감사에도 입력/코드/온도 참조 해시를 보존했다.

새 출력 경로를 지정해 다음 순서로 재현할 수 있다.

```
python tools/run_preslhy_source_ablation.py --phase interface --mode full --droplet-equilibrium-bound --consistent-phase-ambient --downstream-profile enthalpy --output <새 접속 JSON>
python tools/run_preslhy_source_ablation.py --phase field --mode full --droplet-equilibrium-bound --consistent-phase-ambient --downstream-profile enthalpy --interface-checkpoint <접속 JSON> --output <새 전체 JSON>
python tools/run_enthalpy_quadrature_audit.py <전체 JSON> <새 적분 감사 JSON>
python tools/run_preslhy_ambient_profile_audit.py --control reference/preslhy/phase_ambient_consistency_field_complete_2026-09-05.json --candidate <전체 JSON> --temperature-reference reference/preslhy/phase_ambient_consistency_profile_audit_2026-09-05.json --output <새 온도 감사 JSON>
```

분할 계산은 `--trials 11 23`, `--trials 12 24`, `--trials 10 22 25` 후
`tools/merge_preslhy_field_shards.py`를 사용한다. 기존 결과는 덮어쓰지 않는다.
