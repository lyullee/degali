4. 사용 가능한 범위, 계산 실패/자료 누락/검증되지 않은 영역과 개선·악화를

## 작업 방식

- 기존 완료 JSON과 분할 provenance를 확인하여 재사용; 전체 재계산 반복 금지.
- 대표 재현은 시험10(낮은 방출 높이 개방 배관)과23(높은 방출 높이 노즐)을
  우선 점검한다. 이는 이미 상세 진단 대상으로 사용한 사례이며 독립 검증
  모집단을 새로 선정한 것이 아니다. 시험 조건은 원본 reduction으로 확인한다.
- 기준 경로는 기존 corrected measured-source JETPLU. 마지막 전체 완료 후보는
  source-energy/ambient-consistent Gaussian volumetric enthalpy 경로다.
  직전 ambient-consistent density 경로는 후보 효과를 분리하는 대조군으로
  기존 결과에 한해 병기할 수 있다. 성능 좋은 후보를 사후 검색하지 않는다.
- 필요한 물리 보완은 독립적인 원인 근거, 보존/범위 검사와 같은 실험 비교를
  명시한 후 수행한다. 현재 진행 중인 미완성 Q/응력 확장을 자동 이어가지 않는다.
- frozen 소스와 실패 기록은 그대로 유지; 새 검증 도구·결과·보고서는 새 파일.
- 3–5시간은 기존 결과 재사용을 전제로 한 계획 추정이지 완료 보장이 아니다.
  재현에 필요한 필수 계산이 오래 걸리면 정확한 상태를 보고하고 범위를 숨기지 않는다.
