# 전단 에너지와 열 폭 수지의 양립성 — 계산 전 명세

2026-09-05. 기존 7개 독립 열 폭 경계와 다섯 플럭스 원항을 고정한다.
새 현장 계수 적합이나 기본 모형 변경이 아닌, **닫힘 가정의 반증 가능 선별**이다.

## 이번에 시험할 가정

- 변형 좌표에서 방사형인 질량/수소 횡 플럭스 가정을 유지한다.
- 축방향 운동량에도 같은 방사형 복원을 적용한다. 물리 힘 밀도의 짝수
  축성분은 `b_s=g(rho_a-rho) sin(theta)`로 명시한다. 기존 횡풍 항력의
  접선 성분은 0이다. 부력은 힘이며 보존되는 부력 플럭스가 아니다.
- 이것은 단면 평균 축속도 하나를 쓰는 **축방향 전단 축약식**이다.
  곡률의 홀수 항, 횡속도 운동에너지, 법선 응력/압력 수송, TKE 부력 생성과
  TKE 저장·수송을 모두 닫은 Favre RANS 식이라고 주장하지 않는다.
- `D_h/D_C=1`을 한 가지 연구 가정으로 지정한다. 같은 난류 혼합이 두
  스칼라를 운반한다는 시험이며 수소의 분자 Lewis 수가 1이라는 주장이 아니다.
  이전의 고정 Pr/Sc 또는 실측 폭/온도에 맞춘 계수를 재사용하지 않는다.
- 재구성한 전단에 의한 평균 운동에너지 손실 `P`가 즉시 열이 된다는
  국소 평형 가정 `Q_H=P`를 시험한다. 일반적으로 P는 먼저 TKE 생성이며,
  P=열은 항등식이 아니다. 음의 P를 잘라 양의 열원으로 만들지 않는다.
- 상평형 표의 잠열은 이미 H에 포함되어 있으므로 추가하지 않는다.

[JFM 2023의 축대칭 운동량/평균 운동에너지식](https://doi.org/10.1017/jfm.2023.20)은
보존식에서 전단 플럭스를 복원하는 접근의 근거다. Boussinesq·무한 영역
가정을 이 가변밀도 유한 단면으로 그대로 옮기지 않고 아래 식을 따로 유도한다.
[Turbulence Modeling Resource의 에너지식](https://tmbwg.github.io/turbmodels/implementrans.html)은
열 플럭스, 응력 일, TKE 수송을 서로 다른 항으로 구별한다. 이 자료가 위
국소 평형/등확산 가정을 LH2에서 검증했다는 의미는 아니다.

## 유도: 정규화 좌표에서의 축약식

`xi=y/sy, eta=n/sn, q=(xi²+eta²)/2, A=sy*sn`.
`B_M=d(A*rho*u)/ds`, `B_P=d(A*rho*u²)/ds`는 고정 xi,eta에서의 미분이다.
기존 질량 플럭스는 `G_M=(xi,eta)*f_M`, `div(G_M)=-B_M`이다.

```
f_P(q) = integral_0^q [A*b_s-B_P] dt / (2q)
R_P = f_P-u*f_M
chi_P = -R_P/(A*rho*u_q)
P = -2q*R_P*u_q                  # 단위: W/m³ * A
f_K = u*f_P - 0.5*u²*f_M         # 대류 + 응력 일
B_K = d(0.5*A*rho*u³)/ds
B_K + div((xi,eta)*f_K) = A*u*b_s-P
```

이 마지막 식은 위 두 축약 보존식의 곱셈 항등식이다. P를 열로 전환시키는
가정과 분리해 구현·검사한다. 중심 q=0에서는 적분 평균의 유한 극한을 쓴다.

기존 성분 복원 `chi_C`와 질량당 엔탈피 `h=H/rho`로:

```
f_H = h*f_M - A*rho*(D_h/D_C)*chi_C*h_q
B_H = d(A*H*u)/ds
R0 = integral(B_H-P) dxi deta + outward(f_H)
R2 = integral(r²*(B_H-P)) dxi deta
     + outward(r²*f_H) - integral(2*r²*f_H) dxi deta
```

유한 사각형을 원이나 무한 영역으로 바꾸지 않는다. `q0=pi*delta²/8`이면
`outward(f)=16*q0*integral_0^1 f(q0*(1+t²))dt`이다. 방사형 피적분함수의
`integral(r²*f)=(sy²+sn²)*integral(q*f)`이며, 가중 경계 항은
`16*q0*(sy²+sn²)*integral_0^1 q*f dt`이다.
R2에는 고정 정규화 좌표 미분 B_H를 쓴다. 실제 M2의 폭 이동 미분은
물리 약형 양변에 똑같이 나타나 상쇄된다. 경계 이동을 생략한 것이 아니다.

다섯 고정 원항을 만족하는 변화율은 `a+gamma*b`이다. 위 R0,R2도 각각
gamma에 대해 아핀이다. **R2=0으로 gamma를 구하고, 독립적으로 R0=0을
검사**한다. R0만의 근도 진단용으로 기록한다. 두 근을 평균내거나, 다섯 번째
에너지 원항을 바꾸거나, 확산률 비를 적합해서 둘을 억지로 일치시키지 않는다.

## 계산 전 판정 기준

1. 실제 관로/HEM 소스와 국소 동반풍을 복원한다. 이전 원항 재생 1e-8,
   6개 경계 모멘트 재생 1e-9, 기존 선형 보존 원항 잔차 1e-8을 유지한다.
2. 상평형 셀 분할 8/16차에서 수지 각 성분 차를 `max(abs(fine),1)`로
   정규화해 1e-5 이하인지 검사한다. 운동에너지 곱셈 항등식도 같은 기준.
3. 합성 문제에서 국소 운동량/운동에너지 항등식, 양의 점성일 때 P>=0,
   독립 물리 플럭스 차분, 사각형 열 모멘트의 네 면 약형을 검사한다.
4. R2=0의 후보에서 R0를 해당 열 수지 성분의 최대 절댓값(최소 1 W/m)으로
   정규화한다. 허용 1e-5. R2도 가중 수지 성분(최소 1 W m)으로 검사한다.
   저장된 큰 전체 에너지로 나눠 열수지 결함을 숨기지 않는다.
5. 고정 q 1025개와 모든 상평형 셀의 중점에서 chi_C,chi_P>=0,
   전체 사각 단면 `abs(theta')*half_normal_width<1`을 요구한다.
   표본 검사는 전 반경 양성의 엄밀한 증명이 아니다.
6. 위 조건이 모두 통과하고 곡률 지표<0.1인 경우에만 짧은 하류 적분을
   고려한다. 실패하면 해당 가정의 실패를 보존하고 실제 하류/현장 점수는
   계산하지 않는다. 새 기본 모델로 승격하지 않는다.

양립 실패만으로 TKE가 유일한 원인이라고 단정하지 않는다. 등확산 가정,
유한 경계 에너지 유입, 축방향 응력 일/압력 항, TKE 수송이 함께 후보다.
