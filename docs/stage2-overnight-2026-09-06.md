## 이번 실행 순서

1. 같은 방출 유량·엔탈피·환경에서 연구 대조군을 구성한다. 기존 공급원
   차이와 온도 관측 통계(최저값/시간 중앙값)를 각각 명시한다.
2. 상평형 물성→관측 농도/온도 변환과 공급원→하류 에너지 전달을 점검해
   실제 결함 또는 오차 원인 가설을 좁힌다. 앞선 설명의 세 원인을 입증된
   주원인으로 전제하지 않는다.
3. 구체적인 수정은 물리식, 적용 범위, 비교 기준을 먼저 명시하고 추가 코드로
   구현한다. 계수 조정 없이 독립적인 보존/극한/수치 검사를 실행한다.
4. 통과한 후보만 실제 관측 거리까지 적분한다. 기본 비교 모집단은 7개 시험,
   농도38단면·수직17프로파일·시험10/23 동일41온도센서다. 다른 모집단은 따로 표시한다.
5. 온도·농도·폭·중심 높이와 원인별 영향을 함께 보고한다. 기존 결과·실패를
   보존하고, 개선이 없으면 그대로 기록한다. 필요할 때만 추가 물리 개발을 진행한다.

## 실행 규칙

공개 원문은 필요한 물리식/자료에 한해 검색한다. 새 결제·외부 연락·공유는
하지 않는다. 사용자가 요청하지 않은 에이전트 위임을 시작하지 않는다.
같은 계산을 중복 실행하지 않으며 완료 결과는 해시와 입력을 확인해 재사용한다.
수정마다 관련 검사를 마친 후 다음 원인으로 넘어간다. 검증된 개선·중대한 실패·
사용자 판단이 필요한 경우·집중 작업 종료 시에만 후속 실행 알림을 보낸다.

## 새 물리 연결 점검 — 연속 대기 산포 유입

기존 연구 경로와 원본 JETPLU는 x>0에서 대기 산포폭을 x의 멱함수로
계산하지만, x<=1m에서는 유입량에 쓰는 그 폭의 미분을0으로 설정한다.
새 진단 단면의 누락 유입항은 구현된 전체 국소 질량유입의4.8–13.5%였다.

별도 한계이며, 물리적 정확도가 입증된 오류라고 확대하지 않는다.

`docs/prereg-continuous-ambient-spreading.md`를 먼저 고정하고
`addons/continuous_ambient_spreading.py`를 추가했다. x>0에서 기존 폭식을
