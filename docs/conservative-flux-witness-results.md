# 보존적인 횡 유량 보완: 거부안과 국소 가능해

2026-09-06. **시험10의 실패 단면에서 모든 원래 약형식과 총보존식을
유지하는 국소 유량 후보를 찾았다.** 다만 적분망에 따른 변화율 차이와
응력 방향의 추가 자유도가 남아, 하류 폐쇄식으로 채택하지 않았다.
현재 독립 상평형 분할로 원래 수송식의 실제 잔차를 다시 검사 중이다.

## 먼저 실패한 안

질량·운동량 유량에 각각4개의 발산0 성분을 추가했다. 대칭축에서는

운동에너지 유량과 전단 생산을 다시 계산했다.

추가8개 미지수를8개 경계 모멘트의 정확한0 조건으로 결정하는 안은

작았지만 국소 운동량 경계 잔차가 매우 크고 생산항은 음수였으며,

## 다음 검사: 허용 가능한 작은 보정이 존재하는가

추가 유량을 물리 법칙으로 정하지 않고, 먼저 원래 수송식을 만족하는
변화율을 추가 유량의 선형 함수로 나타냈다. 그 안에서 수소/열/운동량
경계4% 이내, 양의 전단 생산, 면 유입과 곡률 기준을 만족하는 작은
유량 보정이 있는지 선형계획으로 검사했다.4%는 기존 초기화의 목표이며
독립 검증의5% 기준을 사후 완화하지 않았다.

## 남은 중요한 한계

두 반복망 사이 변화율 차이는 최대0.00718이다. 유량 보정 선택이
비유일하거나 민감할 수 있어, 이 선택기를 그대로 하류 적분에 넣으면
수치 안정성이나 물리적 일관성이 보장되지 않는다. 독립65광선은 경계와
생산을 확인한 것이지 체적 약형식의 독립 상평형 각도 적분을 대신하지 않는다.
그래서 고정된 후보를 재최적화하지 않고 별도 정밀 약형식과 실제
모멘트 차분을 검사한다.

또한 비반경 응력20.70%는 기존의 단일 chi_P 방향 관계로 표현되지 않는다.
양의 생산만으로 Reynolds 응력 텐서 전체의 실현 가능성이나 난류에너지
수지를 확립할 수 없다. 기존 즉시 전단 열전환 가정 역시 유지된 상태다.

**용어 주의:** 일부 연구 코드/사전 명세의 `scalar_isotropic`은 정규화
단면 좌표에서 하나의 chi로 표현되는 방향 관계를 가리킨다. 실제 좌표의
확산률은 chi*sy²와 chi*sn²이므로 sy!=sn이면 물리적으로 완전 등방성이
아니다. 여기서 말하는 새 비반경 성분은 이 기존 기하학적 방향 관계까지
벗어나는 추가 응력이다. 이 명칭을 실제 등방 Reynolds 폐쇄의 검증으로
읽으면 안 된다.
