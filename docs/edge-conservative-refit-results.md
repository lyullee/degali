# 경계 형상의 보존 재계산

2026-09-05. 이 문서는 고정 수송장 아래의 단면 투영 결과를 다룬다.
새 형상 계수의 하류 수송식이나 실측 정확도 검증이 아니다.

**7/7 조건이 독립 보존량·경계·물성 검사를 모두 통과했다.** 모형 내부의
수소/열 경계 불일치는 기존12.36–25.40%에서0.95–3.63%로 줄었다.
이전 실패 실험의 결과를 수정한 것이 아니라, 새 적분과 제약 재투영을
적용한 별도 결과다. 기본 모델, 물성표, 관측 점수는 변경하지 않았다.

## 이번 변경의 의미

이전 후보는 비교적 거친 단면 적분에서만 보존량이 맞았다. 새 구현은
상평형 표의 구간이 사각 단면의 면과 만나는 각도에서 먼저 나누고,
각 각도의 반경에서도 수정된 형상의 Ti/Y 물성 구간을 다시 나눈다.
따라서 모서리와 면의 구간 전환을 단순히 촘촘한 표본에 맡기지 않는다.

질량·수소·축운동량·총에너지·순부력·열의 물리2차모멘트를 실제 적분한 뒤
여섯 등식을 적용한다. 선형화된 형상 보정 단계부터 모멘트 등식과 보정 크기
제약을 동시에 넣고, 새 형상의 비선형 모멘트를 다시 계산해 확인한다.
등식에 맞지 않는 결과를 잔차 벌점이 작다는 이유로 통과시키지 않는다.

물성, 속도, 기하, 기존 유입/혼합/응력 일, 열/성분 확산률비1은 그대로다.
최적화 계수는 실험 관측값이 아니라 경계 조건과 보존량으로 정한다.
이는 수치 알고리즘과 단면 표현의 보완이지 새로운 난류 상수의 적합이 아니다.

## 재현 가능한 계산 기준

[계산 전 명세](prereg-edge-conservative-refit.md)를 따랐다. 형상 차수는
이전 진단에 선택된 것 그대로(시험10은6차, 나머지는4차)다.
초기 보존 재투영과 이후 경계 개선을 구분하며, 최초 실패 실험은 보존했다.

- 적분: 반경/각도8/8과16/16, 면 교차 탐색1025/2049 표본.
- 영 형상 기준 재현, 실제 모멘트 제약, 독립 차수 간 차이: 각각1e-8 이하.
- 경계: 별도4097개 표본에서 수소·열 각각5% 이하, 기존보다 감소.
- 형상: abs(log correction)<=0.1, 제약 표본33×33과 최종129×129 및
  촘촘한 면 표본으로 확인. 전역 구간 증명은 아니다.
- 상평형 역산, 양의 밀도,0<Y<1, 중심 C/H와 부호 유지.

제약 최소제곱 단계는
[SciPy SLSQP](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html)를
사용한다. 반환 성공 표시만으로 판정하지 않고 실제 등식·부등식을 확인한다.
실제 비선형 재투영에는 새 적분을 다시 적용한다.

표의 경계 백분율은 원래 국소 대류 플럭스로 정규화한 모형 내부 잔차다.
보정 후 분모로 바꾸지 않았다. **실측 농도/온도 오차나 정확도가 아니다.**
모멘트는 이전과 동일한 여섯 척도를 사용하며, 순부력의 척도는
max(abs(F_b),1e-3)이다. 모멘트 오차열은16/16 독립 재적분 결과다.

영 형상의 원래 목표 재현 오차는 최대4.806e-10, 보정 형상의8/8 모멘트
오차는 최대9.342e-11,16/16 독립 재적분 오차는 최대9.041e-11이다.
인접 차수 차이는 최대1.394e-11로 모두1e-8 기준을 통과한다.
이전 각도 비분할 진단의 영 형상2/7 통과 문제는 새 방법에서7/7 통과로
해결했다. 원래 실패 기록 자체는 그대로 남아 있다.

초기 보존 재투영은 시험22에서 최대4회의 스텝이 필요했다. 이후 경계 개선은
시험10/12/24는 추가 스텝 없이,22/25는1회,11/23은2회로 기준에 도달했다.
모든 완료 후보는 최적화 표본의4% 내부 목표에 도달한 뒤 독립4097개 표본에서
최종5% 기준을 통과했다. 단순히 허용 스텝을 못 찾아 멈춘 결과가 아니다.
표본 로그 보정 최대 절댓값은0.0999이며, 원래 한계0.1을 늘리지 않았다.

## 사용 범위와 남은 물리 연결

이 계산에서 수송장은 이전 가우스 약형 상태의 것으로 **고정**되어 있다.
스칼라 형상을 바꾼 뒤의 평균 횡이동·질량 유입·응력·열 수송장을 새로
구성한 것은 아니다. 이전 약형8상태 ODE에 추가 형상 계수를 고정값으로
삽입하는 것도 하지 않았다. 단면 검증 통과를 하류 모형 완성으로 쓰면 안 된다.

후속 순서는 단면의 보존/경계 동시 검증을 마무리한 뒤, 새 형상에서 수송장을
재구성하고 계수의 독립 수송식을 연결하는 것이다. 이후 짧은 구간의 수치
검증을 거쳐 고정 관측38/17/41 비교를 수행한다. 기본 모형/실측 점수는
이번 결과만으로 바꾸지 않는다.

## 코드 검증

새 시험7개는 면/상평형 교차각 재현 및 탐색 세분화, 영 형상의 원래
모멘트 재현, 실제 모멘트 미분의 독립 유한차분, 제약 스텝의 등식/형상
범위와 불가능한 스텝 거부, 실제 비선형 재투영, 폭이 다른 사각형의
물리 열2차모멘트 교차 검증을 포함한다.

최종 비 slow 회귀는 **324 passed,128 skipped,58 deselected (288.10 s)**다.
별도 실행한 새5개 시험은18.67초, 비선형/비등방성2개 시험은156.44초였다.
다른 실제 조건 계산과 병행한 시간이므로 단독 실행 성능 비교값이 아니다.
장시간 현장 계산이나 Linux 전체 Fortran 오라클을 추가 완료한 것은 아니다.

## 실행과 증거 파일

동일 코드/명세/입력으로 조건을 서로 겹치지 않게 나누어 실행했다.
전체 합산은 완료된 각 그룹을 읽고 조건 중복/누락과 입력 해시를 검사한다.
각 `.partial.json`은 중간 기록이며 완결 파일이 생기면 그것을 우선한다.

- `edge_conservative_refit_pilot_2026-09-05.json`: 시험10/11,2/2 통과.
- `edge_conservative_refit_group_a_2026-09-05.json`: 시험12/24,2/2 통과.
- `edge_conservative_refit_group_b_2026-09-05.json`: 시험22/23/25,3/3 통과.
- `edge_conservative_refit_combined_2026-09-05.json`: 중복 없는7조건 합산,
  모두 통과. 각 실행의56개, 합산61개 입력·코드 해시 일치를 확인했다.
- 이전 `edge_enrichment_screen_2026-09-05.json`의0/7 실패와
  `edge_enrichment_phase_diagnosis_2026-09-05.json`의 불완전 검증은 유지했다.

모든 실행은 종료했다. `.partial.json`은 남겨 둔 중간 스냅샷이며 재개를
기다리는 작업이 아니다. 이번 구현은 매 후보마다 물성 구간을 다시 찾는
연구용 계산이어서 아직 실시간/전체 하류 운전 성능을 검증하지 않았다.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
& '.\.venv\Scripts\python.exe' tools/audit_edge_conservative_refit.py reference/preslhy/refit_repeat.json
& '.\.venv\Scripts\python.exe' -m pytest tests/test_edge_conservative_refit.py tests/test_edge_refit_retraction.py -q
```

이전 날짜의 진단JSON에서 초기 조건과 선택 차수를 읽는 재현 도구다.
임의의 새 물리 조건을 자동 처리하는 범용 운전부는 아니다.
