# 사각 단면의 수소·열 형상 보완 — 계산 전 명세

2026-09-05. 기존 약형 수송의 점별 경계 결함을 줄이기 위한 **고정 수송장
단면 투영**이다. 새 형상 계수의 하류 수송식까지 완료하는 단계는 아니다.
기존 기본 모델, Gaussian 경계/하류 파일과 물성표는 변경하지 않는다.

## 필요한 자유도

유한 사각형의 경계에는 q0<=q<=2q0인 여러 반경이 있다. 한 반경 함수만
보정하는 것은 네 면 전체의 유입 조건을 표현하는 데 제약을 준다.
정규화 좌표 a=y/Ly, b=n/Ln에서 a/b 교환과 반사 대칭을 갖는 2차원
짝수 Legendre 기저를 사용한다. 폭 비등방성은 기존 Ly,Ln에 그대로 있다.

```
C = C_G * exp(sum(c_i psi_i(a,b)))
H = H_G * exp(sum(h_i psi_i(a,b)))
```

C_G/H_G는 기존 단면이다. psi_i는 대칭화한 P_(2i)(a)P_(2j)(b)에서 중심값을
빼고 L2 직교 정규화한다. 따라서 중심 C,H는 그대로이고 중심의 첫 미분도
0이다. 실제 rho,Y,T는 수정된 C,H를 기존 상평형 표에 역산해 구한다.
H의 부호를 바꾸거나 온도를 덮어쓰지 않는다.

차수 i+j<=4,6을 각각 시험한다. 미지수는 C/H 각 8/15개, 합계16/30개다.
이는 형상 근사 차수이지 현장 데이터에 맞추는 물리 계수가 아니다.
표본에서 abs(log(C/C_G)),abs(log(H/H_G))<=0.1로 제한한다. 이것은
단면의 국소 보정 범위를 한정하는 수치적 신뢰 범위이며 물리 상수가 아니다.

## 고정 수송장을 명시

이전 약형 단면에서 계산한 f_M, chi_C, f_K와 주변 유입 에너지를 고정한다.
chi_C를 재적합하지 않으며 D_h/D_C=1을 유지한다. 밀도는 새 C/H에서 역산한다.
a=1 면의 바깥쪽 플럭스를 정규화된 면 좌표 크기 L로 나누면:

```
F_C = Y*f_M - A*rho*chi_C/(2*q0) * dY/da
F_H = h*f_M - A*rho*chi_C/(2*q0) * dh/da
F_C,target = 0
F_H,target = (u_a²/2)*f_M-f_K
```

나머지 면은 반사/교환 대칭으로 평가한다. 새 밀도/조성의 공간 기울기는
상평형의 암시적 미분으로 계산한다. rho*h 구배를 h 구배로 바꾸어 쓰지 않는다.
주변 상태로 유입 총 플럭스를 정하는 근거는
[열 유입](https://doc.comsol.com/6.4/doc/com.comsol.help.heat/heat_ug_theory.07.009.html)과
[성분 유입](https://doc.comsol.com/6.3/doc/com.comsol.help.cfd/cfd_ug_chemsptrans.11.139.html) 조건이다.

**새 형상에서 수송장/응력/하류 미분을 재구성하지는 않는다.** 여기서의
경계 개선은 고정 수송장에 조건부다. 이전 8상태 ODE에 새 계수를 고정값으로
끼워 넣거나, 반경 전용 적분/관측점 함수에 새 단면을 넘기지 않는다.

## 보존 제약과 계산

A, u(q), theta, x,z 및 중심 C/H는 고정한다. 기준 단면을 같은 물성으로
상평형 셀 분할 16차에 재적분하여 다음 여섯 독립 목표량을 고정한다.
M, H2, 축운동량, 총에너지, 부력 F_b, 물리 열 2차 모멘트 M_H2.
벡터 운동량의 두 성분은 고정 theta에서 함께 보존된다.
원래 저장 경계와도 기존 플럭스/힘 적분 기준으로 비교한다.

주어진 차수의 형상에서 65개 면 표본의 두 플럭스 제곱잔차를 최소화하되,
여섯 모멘트는 비선형 등식으로 유지한다. 모멘트 Jacobian의 영공간에서
경계 잔차를 줄이고, 매 시도 뒤 모멘트 등식으로 Newton 재투영한다.
임의의 모멘트 벌점으로 보존 오차를 숨기지 않는다. 부족한 행렬 계수/비물리
상태/정체는 실패로 기록하고 계속 계수를 늘리지 않는다.

최적화의 단면 적분은 Gauss 48차에서 시작해 96차로 다시 투영한다.
192차, 필요하면 384차 실제 단면 재적분으로 확인한다. 구배 역산과 힘의
작은 차이는 별도 검사가 필요하므로 경계 개선만으로 통과시키지 않는다.

## 판정 기준

- 모멘트 등식 정규화 오차 <=1e-8. 힘의 척도는 max(abs(F_b),1e-3),
  질량/수소 최소1e-12, 운동량/에너지/M2 최소1이다.
- 최종 이웃 두 적분 차수의 6개 모멘트 차 <=1e-5. 미달하면 결과는
  수치 미확인으로 남기며 그 형상을 완료/채택으로 표시하지 않는다.
- 최적화에 쓰지 않은 균일4097개 면 표본에서 각각 수소/열 최대 결함 <=5%,
  동시에 기존 동일 표본의 결함보다 감소해야 한다. 분모는 기존 국소
  대류 플럭스이므로 보정에 유리하게 바꾸지 않는다. 실측 오차율이 아니다.
- 물성 역산, 0<Y<1, 양의 밀도, 표본 로그 보정 범위를 모두 확인한다.
- 4차/6차 결과를 모두 보존한다. 낮은 차수의 실패를 숨기지 않는다.
  큰 형상 변화나 불량 수렴이 필요하면 이번 투영을 채택하지 않는다.
- 이번에는 하류/현장 점수 계산과 기본 승격을 하지 않는다.
