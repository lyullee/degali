# 같은 41개 온도 기록의 평균 통계 감사 — 2026-09-06

목적은 새 확산식을 맞추는 것이 아니라 정상 단일 온도 예측과 비교한 관측
통계의 차이를 확인하는 것이다. 기존 min/p05/median 결과는 변경하지 않는다.
해당 통계를 이미 본 상태에서 추가한 진단이며 독립 검증으로 부르지 않는다.

동결 stage1_single_image의 정확히 같은 41개 channel/trial 키를 사용한다.
원본 temperature_source_rate_audit의 해시와 Excel 행 범위를 그대로 읽는다.
시험10 Flexlogger 30:78, 시험23 28:125(양 끝 포함). 변환된 섭씨 채널만
사용하며 원시 전압, 배관 온도, 다른 시트와 농도 센서는 합치지 않는다.
원본 XLSX는 read_only/data_only로 읽고 저장/수정하지 않는다.

각 센서의 finite 값 수와 기존 min/p05/median을 1e-8 K 이내 재현해야 한다.
원래 시간 열의 1초 등간격을 확인한다. 산술평균, 표본 표준편차, 모멘트
왜도(편향 보정 없음), p95, 평균-중앙값, 원래 CONTROL 이하 표본 비율을
추가 저장한다. 전 구간의 trapezoid 시간평균도 경계 반표본 차이를 별도로
보이되 주 분석은 기존 표본 집합 전체의 산술평균이다. 누락/불규칙 시간은
숨기지 않고 실패로 남긴다. 평균 오차에 독립 표본 가정의 신뢰구간을 붙이지
않는다(시간 상관/실험 체계오차 미평가).

같은 BASE_SINGLE_IMAGE와 CONTROL의 변경 없는 예측을 각 통계와 비교해
MAE/RMSE/평균 부호 오차를 별도 보고한다. 평균 기준 수치가 작아져도
모델의 오차 개선 또는 새 물리 채택으로 세지 않는다. 평균 아래의 낮은
중앙값을 허용하는 수학적 분포가 실제 관측 PDF라는 주장도 하지 않는다.
실측 thermocouple 시간평균은 Reynolds 평균과 자동으로 동일하지 않는다:
프로브 응답/열교환, 정상성 및 앙상블-시간 평균의 대응은 별도 가정이다.
임의의 시간 구간 변경, 센서 제외, 분산/난류 계수 추정은 하지 않는다.
