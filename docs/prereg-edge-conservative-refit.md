# 경계 형상 보존 재계산 — 계산 전 명세

2026-09-05. 이전 형상 선별/진단은 실패 기록으로 보존한다. 새 파일로
각도 적분을 보완하고 같은 물리 가정 아래 형상을 다시 투영한다.
기존 코드/기준/실측 점수/기본값은 변경하지 않는다.

## 적분 보완

새 C/H의 상평형 표 경계가 사각 면과 만나는 각도를 먼저 찾는다.
면에서 Ti,Y를1025개 각도로 탐색해 각 물성표 경계의 부호 변화를 포착하고
이분법으로 교차각을 정한다. 물성표 구간 안에서 끝나는 내부 극값은
적분 경계로 필요하지 않으나, 표본 사이에 숨는 교차/접선은 이 방식으로
엄밀히 배제하지 못한다. 각도 탐색2049개와 적분 차수 증가로 독립 확인한다.
각 각도에서는 기존과 같이 새 형상의 반경 Ti/Y 경계를 다시 분할한다.
각도8/반경8부터16/16까지 세분화한다. 영 형상은 원래 가우스 셀분할
목표와1e-8 이내, 실제 모멘트의 이웃 차수 차이는1e-8 이내로 확인한다.
이 강화된 수치 확인은 원래 모멘트 제약1e-8을 완화하지 않는다.

## 보존 및 경계 재투영

이전 사후 진단에 선택된 차수와 계수를 그대로 시작점으로 사용한다:
시험10은6차,11/12/22/23/24/25는4차. 다른 차수나 새로운 물리 계수를
추가해 맞추지 않는다. 여섯 목표량과 그 척도는 이전 값 그대로다.
새 셀분할 실제 적분의 미분을 계산하고, 여섯 보존 등식과 표본 로그 형상
범위 abs(log correction)<=0.1을 스텝 계산에 함께 넣는다.

수치 스텝은 선형화한 경계 잔차 최소제곱과 작은 스텝 정규화를 사용한다.
모멘트는 등식이고 형상 범위는 선형 부등식이다. 정규화는 스텝 안정화용이며
수송 계수가 아니다. 제약이 실제 스텝에 들어가는
[SLSQP](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-slsqp.html)를
사용하되 반환 성공 여부만으로 통과시키지 않고 실제 등식/부등식을 확인한다.
최초 보존 재투영과 이후 최대20회 경계 개선을 구분해 기록한다.
새 실제 모멘트를 다시 계산해 비선형 보존을 확인하고, 필요하면 재투영한다.
정체/비물리/지원하지 않는 단조 경로는 실패로 남긴다.

보정의 신뢰 범위는33×33 내부/면 표본에서 제약으로 넣고, 최종129×129
표본과 독립4097개 면 표본으로 확인한다. 형상장 C/H의 부호, 양의rho,
0<Y<1, 상평형 역산과 중심값을 검사한다. 이는 전역 구간 증명이 아니다.
혼합률·유입 질량·응력 일·속도·기하·열/수소 확산률비1은 계속 고정한다.

2. 독립4097개 면 표본의 수소/열 최대 잔차가 각각<=5%이고 기존보다 감소.
3. 신뢰 범위와 물성 검증 통과. 원본 실패를 덮어쓰지 않음.
4. 새 형상 수송장/계수 수송식/하류/현장 점수/기본 승격은 이번 범위 밖.

고정한 뒤 실행한다. 예비 실행에서 발견한 수치 구현 문제를 변경해야 하면
