# 총질량·수소 보존으로부터 횡방향 혼합 복원

2026-09-05. 구현/7개 경계 계산 전에 고정한다. 관측값을 맞추지 않는다.

## 이번 범위

새 beta_H 하류 ODE를 임의로 닫는 대신, 다섯 플럭스가 허용하는 국소
상태 변화의 1자유도 집합을 만들고 그 각각에 필요한 횡방향 이동과 수소
혼합을 복원한다. `gamma=dlog(beta_H)/ds`를 미지수로 보존한다.
gamma=0은 이 아핀 집합의 좌표 원점이지 새 하류 모형의 선택값이 아니다.

기존 소스/환경/유입 관계는 유지한다. 근접장 계산을 다시 적분하지 않고도
원래 측정 관로/HEM 소스와 국소 동반풍에서 소스 의존 계수를 재구성한다.
저장된 기존 하류의 첫 원항을 재현하는지 확인한 후 새 경계에서 원항을
평가한다. 물성 재생용 임시 소스를 유입 원항에 사용하지 않는다.

## 명시적 새 형상 가정

평면 곡선 단면, `xi=y/sy`, `eta=n/sn`, `q=(xi²+eta²)/2`,
`A=sy*sn`, `m=1-kappa*n>0`에서 **변형 좌표의 횡방향 보존 플럭스가
방사형이고 무회전인 분포**를 선택한다. 이는 연속식만의 유일한 결론이
아니며, 횡풍 와류·지면·비틀림 또는 추가 무발산 흐름은 포함하지 않는다.

```
B_M(q) = partial_s(A*rho*u)|xi,eta
B_C(q) = partial_s(A*C*u)|xi,eta
f_M(q) = -integral_0^q B_M(t)dt/(2q)
f_C(q) = -integral_0^q B_C(t)dt/(2q)
G_M = (xi,eta)*f_M
G_C = (xi,eta)*f_C
div(G_M)=-B_M, div(G_C)=-B_C
```

中心은 `f(0)=-B(0)/2` 극한으로 처리한다. C는 rho*Y이다.
실제 횡방향 평균 속도는 좌표 이동을 다시 더해 복원한다:

```
v_i = sigma_i*xi_i/m * [u*dlog(sigma_i)/ds + f_M/(A*rho)]
R_C = f_C - Y*f_M
chi = -R_C/(A*rho*dY/dq)     [1/s]
D_i = sigma_i²*chi/m         [m²/s]
```

이 D는 정규화 좌표에서 방사형인 플럭스를 표현하는 **대각 비등방 텐서**다.
원형·직선 단면에서만 두 성분이 같아진다. 보편적인 등방 난류 확산률을
발견했다고 부르지 않는다. 음의 chi를 0으로 잘라서는 안 된다.
Y_q가 0인데 잔여 플럭스가 0이 아니면 유한 확산률로 표현 불가이다.

엔탈피 쪽 연결은 외부에서 명시한 `r_D=D_h/D_C`에 대해서만
`R_H=-A*rho*r_D*chi*dh/dq`와 `G_H=(xi,eta)*(h*f_M+R_H)`를 반환한다.
이번 실경계에서는 r_D나 기계적 에너지 교환을 선택하지 않는다. 따라서
열 모멘트 연산자에 연결할 수는 있어도 닫힌 에너지 ODE는 아직 아니다.

## 수치와 판정

- 상평형 표의 셀 경계를 찾아 구간별 벡터화 적분. 단조로운 Ti(q),Y(q)
  가지에 한정하고, 표/단조 조건 위반은 거부한다. 적분 8/16차와 독립
  촘촘한 격자의 유량 미분을 비교한다. 기존 표를 매끈하게 바꾸거나 보간
  구배를 제거하지 않는다.
- 알려진 일정밀도 Gaussian 확산해에서 복원된 물리 횡속도는 0,
  복원 D는 주어진 정확한 D와 일치. 변형 좌표 유량과 실제 유량을 구별한다.
- 곡선·비등방 단면의 제조해로 국소 발산과 네 면의 적분 수지 확인.
- 실제 7개 경계: 기존 원항 재생 상대/정규화 오차 <=1e-8;
  다섯 선형화 플럭스 잔차 <=1e-8. 차수 변화 <=1e-5 및
  8/16차로 구한 횡 보존 플럭스의 정규화 차 <=1e-5를 각각 검사한다.
- 각 단면에서 고정 q 격자 513개로 `chi_base+gamma*chi_response >=0`의
  교집합을 구한다. 표본상의 필요조건이며 전체 단면 양성의 증명이 아니다.
  불가능한 구간/조건은 기록하고, beta 변화율이나 r_D를 사후 선정하지 않는다.
- 소스/경계/원항/수치 검사를 통과해도 현장 정확도 또는 하류 해의 승인이 아니다.

참고: [Milton-McGurk et al. (2023), JFM](https://doi.org/10.1017/jfm.2023.20)
은 Gaussian 평균 형상과 보존식에서 반경방향 유속/스칼라 플럭스를 유도한다.
그 원식은 Boussinesq 축대칭·무한 단면이므로 그 계수나 부력 보존식을
저온 LH2 혼상에 복사하지 않는다. 위 가변밀도·유한·변형 좌표의 식과
형상 가정은 이번에 별도로 도출했다.
