# 저온 수소 EOS 선별과 소스 에너지 연결 감사 — 2026-09-05

## 범위와 선행 결함

농도 관측에 맞춰 계수를 바꾸지 않는다. 순수 수소 EOS 선별, 소스 보존식 수정,
하류 프로파일 수정은 별개 판정이다. 이번 작업은 앞의 두 가지를 먼저 한다.
2026-09-05 HEM/para 결과 파일은 수정 전 연구 이력이며 덮어쓰지 않는다.
기존 기본 DEGADIS 경로와 검증된 순수 기체 소스에는 새 경계값을 자동 추가하지 않는다.

코드 감사에서 발견한 두 가지 에너지 연결 결함:

1. 측정 배관은 이동하는 유체인데 증발 종점 수지의 유입이 정지 저장조 엔탈피뿐이었다.
   HEM 경로에 유입 운동에너지 u_pipe²/2 (J/kg-H2)를 전달한다.
   압력 일은 엔탈피에 이미 들어 있으므로 별도 중복 가산하지 않는다.
2. HEM 소스가 전달한 T, rho, Y만으로 근접장이 **모든 공기가 기체라는 엔탈피**를
   다시 만들었다. 응축상 에너지와 수소 잔류 엔탈피가 이때 사라졌다.
   명시적 소스 엔탈피 경계에 혼합물 kg 기준 엔탈피, 주변 기준 온도,
   수소 종, 수소 엔탈피 기준값을 기록하고 가우스 발달 보존식으로 넘긴다.
   운동에너지는 이 경계 엔탈피에 포함하지 않고 수지에서 한 번만 가산한다.

종점 공기 고체 엔탈피는 기존 N2/O2 근사, 근접장은 기존 성분 물성표를 사용한다.
이번 변경은 전달 에너지를 보존하며 두 모델의 상평형/열용량을 통일하는 변경은 아니다.
HEM 종점의 공기 조성과 실제 습공기 조성 차이도 남는다.

## 결과 실행 전 고정한 판정

- 순수 H2/para/ortho HEOS의 체적비 v_real/v_ideal=Z와 잔류 엔탈피 h-h_ideal을
  함께 계산한다. 기체가 안정하지 않은 상태는 강제로 기체로 계산하지 않고 거부한다.
- 4개 측정 노즐 11/12/23/24를 모두 사용한다. 개방 배관의 미확인 압력을 추정하지 않는다.
- 분리 비교: 수정 전 경계, 유입 운동에너지만 수정, 운동에너지+상 엔탈피 경계 수정.
  근접장 계수, 반경 41점, RH, 10D 종점, 수치 허용오차는 모두 고정한다.
- 원래 측정 배관에서 독립 재계산한 전체 에너지와 가우스 발달면 에너지의 상대 오차
  1e-8 이하를 코드 보존성 기준으로 삼는다. 솔버 내부 잔차만으로 판정하지 않는다.
- 시작/끝과 중간 단면의 T, rho, Y 및 반경별 프로파일을 저장한다.
- 7개 기존 접속 시험을 재실행하되 기존 허용 기준은 변경하지 않는다.
  전부 통과하면 기존 38개 농도 단면과 17개 수직 프로파일의 고정된 5지표
  판정도 재실행한다. 성공 사례가 겹치지 않는 두 작업 묶음은 통합할 수 있다.
- 순수 H2의 Z를 혼합기체 전체에 곱하지 않는다. 희석/응축/종간 상호작용을 포함한
  혼합 EOS와 에너지 관계가 없이는 일괄 체적 보정을 모델 기본값으로 넣지 않는다.
- 이번 시험은 **보존성 및 민감도 감사**이다. 새로운 독립 실험 정확도 검증이 아니며
  예측 온도가 변하는 것만으로 실험 오차가 줄었다고 판정하지 않는다.
