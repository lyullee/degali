## Submission control

Before upload, the corresponding author should confirm that every locally
regenerated item has a matching input SHA-256 and that figure captions
state whether a result is measured validation, numerical verification or a
conditional boundary. No output with a raw third-party workbook, report PDF or
unresolved source/weather/operator identity may be promoted to the main paper.

`tmp/ijhe-decision-scenarios/` and `outputs/transient-3d-error-study-2026-10-08/`.
