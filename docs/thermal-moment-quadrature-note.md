# 열 구배 적분의 수치 보완

2026-09-05. 기존 고정 차수 GL 결과를 지우거나 판정 기준을 완화하지 않는다.

고정 경계의 평균 대류 M2는 Gaussian H*u만으로 정해져 매끄럽다. 반면
`-rho*d(H/rho)/dq`는 상평형 표의 부분 미분을 포함하며, 표의 셀 경계에서
불연속인 기울기를 갖는다. M2 적분이 매우 정확해도 열 구배 적분까지 같은
정확도를 가진다고 할 수 없다. 첫 trial 10의 GL2048/독립 GK21 차는
3.574e-5로 사전 기준 1e-5를 넘었다.

수치 보완은 물리 상수를 조정하는 대신, 체적 항과 네 면의 경계 항을 각각
적응형 GK21로 계산하는 것이다. 공간 좌표도 독립 감사와 다르게 선택한다.
체적은 직접 q, 경계는 법선 거리/sigma_n를 사용한다. 각 항의 오차 추정치는
`max(abs(component),1)`로 정규화하며 요청 허용 오차는 기본 1e-7이다.
두 큰 항의 상쇄로 작아진 순값을 적분 오차의 분모로 쓰지 않는다.
수치 추정치가 기준을 넘거나 subdivision 한도에 도달하면 converged=False이다.

추가 검증: 앞서 작성한 독립 감사의 적응형 결과와 체적/경계 각 항 및 순값을
같은 정규화 기준 1e-5로 비교한다. 매끄러운 제조 열 구배에서는 독립 사각형
면 적분과 일치해야 하며, 허용 오차 요청을 10배 좁혀 수렴도 검사한다.
기존 GL 실패 기록은 유지한다. 실험 정확도, D_h, 하류 폐쇄식은 변하지 않는다.
