# 액상 비이상 혼합의 평형·혼합열 보완 — 2026-09-06 12:10 KST

선택형 `liquid_excess_potential.py`에 질소·산소 액체의 초과 Gibbs 함수와
그 미분으로 얻는 혼합열·엔트로피·열용량·화학퍼텐셜을 함께 구현했다.
활동도만 바꾸고 혼합열을 누락하는 경로가 아니다. 새40검사와 관련10파일
265검사가 통과했다(4.39초). 기존134파일/런타임과 선행·이번 입력 해시는 불변이다.

hE 최대82.2445 J/mol, CpE 최대1.73185(이차)/1.77765(PCHIP)J/mol/K다.
유한 격자 값이며 모든 온도·혼합고체의 보편적 상한이 아니다.

새 확산장 적분/관측41온도 재평가/기본판 채택은 하지 않았다. 국소0.39K
규모를 기존 수십 K 잔차의 해소라고 보고하지 않는다. 범위 밖의 혼상은
여전히 미지원이며 이 후보를 자동으로 전체 액화수소 모형에 붙이지 않는다.

## 구현한 식과 물성 근거

원문 [NBS Report3921](https://nvlpubs.nist.gov/nistpubs/Legacy/RPT/nbsreport3921.pdf)의
printed p12 eq1a/b, p24 Table4, p25 Table6를 PDF43/77/79에서 직접
시각 확인했다. PDF 읽기 지침에 따라 식의 첨자·체적 단위·표 값을 확인한 뒤
코드로 옮겼다. 1955년65/70/77.5K 표를 사용했으며 PRESLHY 값을 맞추는
회귀계수는 추가하지 않았다. 원문의 활동도 상관식은 실험적으로 정해진 것이다.

```
gE = 4.184*A*V_N*V_O*x*(1-x)/(x*V_N+(1-x)*V_O)
sE = -gE_T; hE = gE-T*gE_T; CpE = -T*gE_TT
muE_N = 4.184*A*V_N*phi_O^2
muE_O = 4.184*A*V_O*phi_N^2
```

명시적으로 선택하는 이차/PCHIP 보간은 본 구현의 수치 선택이지 원문의
혼합열 측정식이 아니다. PCHIP의70K Cp 좌우 차이도 기록/검사했다.
vE=0이고 체적분율의 표준체적은 상관식 내부에만 사용한다. 공통 순수액상
G의 실제 체적은 유지한다. 원문 자체도 부피 가산성의 한계를 지적한다.
기체는 이상, 수소는 불용성, 혼합 고체·수소 용해·기체 초과 G는 빠져 있다.
국소 대조의 수소/기체 엔탈피 보간과 물/얼음 열량 장부는 이전과 같다.

새 flash는 양의 비응축 기체가 있는 경우에 한정한다. 전체 기체에 대한
액체 접선평면 거리 최소값으로 응축 여부를 검사하고, 비이상 활동도와
Rachford-Rice의 조성 일치 근을 구한다. 성분 보존·화학퍼텐셜 동일성,
별도 제약 총 G 최소화, 순수성분·전기체·배율·물 저장량 조건을 검사했다.
이것은 구현된 기체/액체 내 검증이며 빠진 고체까지의 상안정성은 아니다.
